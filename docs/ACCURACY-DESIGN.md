# 全场普攻、精准与闪避设计

2026-10-19，R012 更新。用户已接受**精准、闪避**加减方案与默认值；设计已确认，尚未改动游戏代码。具体英雄、技能、装备后续设计，下一步基础规则见[接续清单](FOUNDATION-NEXT.md)。

## 已确认方向与基础数值

- 普攻能攻击所有位置，打远处要吃命中减益。
- 普通攻击的基准命中为 **95%**。
- 相对于双方 1 号互相攻击，每多跨一格：近战减 **5 个百分点**，远程减 **2 个百分点**；是百分点相减，不是连续乘 95% 或 98%。
- 英雄、怪物使用同一套规则。
- R011 将命中相关属性改为**精准、闪避**，替代原设计里专注/移速承担的命中职责；不再用移动速度间接表示闪避。移速是否作为未来实际移动属性保留，另有玩法需求时设计，不在此新增用途。
- R012 已确认下方加减公式、基础精准 95、基础闪避 0 和普通攻击修正 0；精准可超过 100 抵消惩罚，命中只判一次。
- 以上为已确认设计，未实施；特殊招式和概率/距离惩罚上下限仍为建议，不能混同为已确认数值。

## 当前实际运行的旧系统

功能基线 `f98cd2c`，R011 核对 HEAD `dbef0ef` 的代码，R012 开始 HEAD `67d9692` 未含后续游戏代码变更：

```text
普攻命中率 = clamp(攻击者专注 / max(1, 目标移速), 0, 1)
```

专注与移速基础都是 100；100 对 100 是 100% 命中，100 对 125 是 80%。普攻默认可闪避、可暴击；伤害技能默认必中、不暴击，定义可覆盖。95% 基础命中与距离惩罚尚未接入。当前 `focus`/`move` 的字段、面板、装备和存档仍是旧结构；不能用设计文档推断其已迁移。实际契约见 [COMBAT](COMBAT.md)。

R009–R010 的 `招式系数 × 专注 / 移速 - 距离惩罚` 曾为建议公式，**R012 已确认由下方精准/闪避加减方案替代**；R010 已确认的 95% 与每格 5/2 个百分点继续保留。

## 已确认的加减算法（上下限仍待定）

第一版角色基础精准 **95 点**、基础闪避 **0 点**，普通攻击的招式精准修正 **0 点**：

```text
未裁剪命中值 = 攻击者精准 + 本次招式精准修正
                - 目标闪避 - 距离惩罚
实际命中率 = 对未裁剪命中值应用概率上下限后 / 100
```

这里 1 点对应 1 个百分点。精准和闪避是参与对抗的数值，不是面板上对所有目标都固定的概率；精准可以超过 100，超出的部分用于抵消敌人闪避和距离惩罚，不能先把角色精准裁到 100。

不再另加一次基础 95：它已经体现在角色基础精准里。也不做命中之后再掷一次闪避的双重判定。实际概率必须在 0%–100% 内；是否额外设 30% 保底命中仍待平衡，不能把此前建议当成已确认值。

| 攻击者精准 | 目标闪避 | 距离惩罚 | 招式修正 | 未触及上下限时的命中 |
| --- | --- | --- | --- | --- |
| 95 | 0 | 0 | 0 | 95% |
| 95 | 10 | 0 | 0 | 85% |
| 105 | 10 | 0 | 0 | 95% |
| 95 | 0 | 20 | 0 | 75% |
| 95 | 10 | 20 | 0 | 65% |
| 95 | 0 | 0 | -10 | 85% |

装备“精准 +5”提高 5 个百分点的未裁剪命中；“闪避 +5”让攻击自己的常规招式降低 5 个百分点。上下限已经生效时，最终概率变化可能不足 5 个百分点。相较旧比值算法，这是实质性规则变化，不是只换面板名字。

## 位置与距离

双方 1 号最前，5 号最后：

```text
我方 [5][4][3][2][1] | [1][2][3][4][5] 敌方
额外距离 L = 自己位置编号 + 敌方位置编号 - 2
距离惩罚 = L × 本次行动每格衰减 K（百分点）
```

普通近战 K=5、普通远程 K=2 已获初版确认。1→5 和 5→1 都是额外 4 格；5→5 是额外 8 格，不能按双方编号差的绝对值计算。基础精准 95、目标闪避 0 时，1→5 近战命中 75%，远程命中 87%。此前提出最多减 25 个百分点的距离惩罚上限仍是建议；最终公式若加上限需在说明中明确，不视为已定稿。

每个普攻/Q/W/E/R 分别配置选敌优先级、招式精准修正、距离衰减率与目标数量。位置影响命中收益；暂不普遍加入“站错位置不能出招”的硬限制是设计建议。少数固定范围技能、低衰减或忽略距离的特殊招式后续设计。

## 高伤害、效果与结算

- 重击可以预设精准修正 -10、精准射击预设 +10，均为示例，不是正式内容。攻击力、法强、增伤、穿透或暴击成长不会自动降低命中。长冷却或高法力消耗也可平衡高伤害，不必都叠加低命中。
- 发射时按本次行动、双方属性和实际站位保存命中与伤害快照；命中后才有暴击收益。原单位死亡后旧弹道不会误伤同位置新怪。
- 一次攻击对每个目标仅有一次命中判定；护盾不再判一次闪避。未命中不造成生命/护盾伤害、伤害吸血或命中附带控制；“攻击时”与“命中时”触发分别处理。
- 群攻按各目标的闪避和距离分别判定。持续伤害成功施加后不每跳重掷；治疗、增益和护盾给予不判闪避。上述技能细节是建议，需随内容落地验证。
- 必中技能应明确写明可绕过闪避及距离造成的失误，但不能无视护盾/减伤；特殊例外以冷却、消耗或其它参数平衡，不默认所有法术必中。
- 精准、闪避装备都可形成构筑，但不应让普遍高闪避迫使所有英雄必须买精准。闪避保持较难提升的方向，具体成长与装备数值后续设计。

## 后续实施与迁移注意

进入代码实施时，需要同时处理双方基础属性、英雄/怪物定义、装备/状态修改、面板说明、实际结算和旧存档。建议新字段分别为 `accuracy`、`evasion`；旧 `focus`/`move` 不能只改标签，旧移速 100 也不能直接变成闪避 100。旧装备及存档按版本迁移，必须验证不重复转换、不丢装备且旧属性不会和新属性叠加生效；具体映射待实施时结合现有存档决定。

验证应覆盖双方规则一致、95% 基准与每格衰减、精准超过 100 后仍可抵消闪避、概率上下限、群攻分目标、未命中触发/吸血、伤害成长不改变命中、旧弹道隔离、预览不消耗随机数及存档迁移。用整关击杀/金币、清场时间、低频技能空挥率和构筑表现验证平衡，不能只验证算式。
