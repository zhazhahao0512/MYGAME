# 战斗 V2：慢速补怪、可保存指令与挑战传送带

2026-10-19（北京时间），R018 / [D004](decisions/D004-battle-v2.md)。R018 当轮仅为设计与示意图，**当时没有修改游戏运行逻辑**；R024 实施接续见下方提示。已确认要求与下方实现建议分开；界面图的时间、血量、奖励、英雄/怪物名字均为占位。当前实现仍见 [COMBAT](COMBAT.md) 与 [FRAMEWORK](FRAMEWORK.md)。

> R024 接续：用户已批准按概念图开始修改，现已接入双详情、持久指令、批次补怪和挑战队列，见 [D009](decisions/D009-battle-v2-implementation.md) 与 [当前运行契约](COMBAT.md)。下文保留 R018 设计背景；当前工程取值以本页末尾为准。

## 本轮已确认

用户明确改变出怪节奏：怪物更强、补怪更慢，一只怪应有数秒至十多秒的交战空间，让手动指挥有价值；具体时间和数值待试验。

异步澄清已获得答复：

1. **死亡保留空位**，剩余怪物不前移；补怪按各怪推荐位置填入。
2. **保存优先位置**：该位置或附近有怪就优先考虑，再用所选自动策略筛选；目标死亡后不需要重新设置。

用户还明确：

- 每名英雄可切换五种自动选敌方式：命中率最高、生命比例最低、当前生命最低、最近、最远；默认使用命中率最高。
- 先点英雄，再点敌人，手动设定该英雄的优先位置及附近区域；死亡后按保存设置自动锁敌。
- 英雄下方显示一个数字，提示正在攻击哪个敌方位置。
- 自动补怪之外增加挑战传送带，展示较强怪物或敌方英雄，点击加入后续刷新列表，击败奖励更高。
- 页面改为左下选中英雄详情、右下敌人详情；美术仍可用文字方框，先看示意图，不急于改游戏。

这替代 R015 的“只由英雄预设、不提供手动策略”推荐，也结束“是否自动前移”的备选讨论。保留固定位置不等于保留旧的死亡后 2 秒原槽补怪算法。

## 一、战场与慢速补怪建议

固定编号仍为：

```text
我方 [5][4][3][2][1]  |  [1][2][3][4][5] 敌方
                               ↑ 死亡留空，不压缩队列
```

建议用一个显示在队列旁的**下次补怪倒计时**控制下一批入场，而不是每个死亡格直接复制原怪。每批按本关刷新预算，从普通刷新池和已接受挑战中选择可入场单位；优先安排已接受且有适合空位的挑战，再用普通怪补充。同时最多五个敌人，不覆盖活单位、不把它们挤走。批次间隔、每批数量与开局数量均为待调参数。

每类怪物有有序的推荐位置，例如前排护卫 `[1,2]`、后排施法者 `[4,5,3]`。入场只找列表中的空位；没有适合位置则保留待入场，显示“等待后排空位”。可先处理其它位置兼容的请求，避免队首阻塞整批；相同条件按入队顺序处理。是否允许长期等待后降级到其它位置，留作 Q007，不默认塞错位置。

慢节奏主要从生命、伤害/防御、出场数量和补怪间隔一起调，不把所有属性等比例提高，尤其不靠极高闪避让怪变“耐打”。普通怪“数秒到十多秒”是体验目标，不是代码强制最短存活时间；队伍强度、集火与后期构筑仍可加速击杀。现有每层 25 秒不直接当新节奏的定稿值，关卡时长也需配套调整。

**固定空位与距离**：已确认的距离仍按实际固定位置计算，前排死亡不会自动使 5 号变成 4 号。直接收益是前排不再吸引攻击、自动选敌会转向后排且补怪较慢。若用户希望空位另外提高后排命中，需要另定“穿过空位不算距离”或遮挡机制，本轮不擅自改变距离公式，见 Q008。

## 二、五种自动策略

五个按钮属于**当前选中英雄**，不是全队一键更改。每名英雄独立保存；默认最高命中，不再把职业模板强制绑定到英雄。特殊技能可明示自己的合法目标/选敌规则，治疗不继承敌方选敌策略。

| UI 按钮 | 筛选规则 | 说明 |
| --- | --- | --- |
| 命中最高 | 预测实际命中率从高到低 | 使用当前行动的精准修正、目标闪避与距离；不是预测最高伤害，不进行随机试射 |
| 血量比例最低 | 当前生命 / 最大生命从低到高 | 不把护盾计入生命比例 |
| 生命值最低 | 当前生命绝对值从低到高 | 不等于可一击击杀，不预扣在途伤害 |
| 最近 | 当前固定位置距离从近到远 | 当前横队一般即前排优先 |
| 最远 | 当前固定位置距离从远到近 | 当前横队一般即后排优先 |

建议相同评分时以距离近、位置编号、单位编号稳定处理；命中达到 100% 的多个候选按实际概率并列，不按溢出的原始精准分数制造隐藏优先级。

## 三、手动位置偏好与实际目标

保存的是玩家指令，实际攻击锁定仍使用唯一单位编号，二者不能混为一谈。

建议每名英雄保存：`自动策略`、`优先位置（可为空）`、`邻近范围`。推荐第一版邻近范围为左右各 1 位，图中点敌方 4 号后显示“优先位置 4 · 邻近 3 / 5”，该半径仍为建议。英雄换位时设置随英雄成员身份走，不附着于我方某个格子；建议在本次远征中跨关保存，重新开始远征恢复默认，具体保存范围见 Q005。

建议流程：

1. 点英雄：选中并进入一次“为该英雄指定目标”的状态，左下显示操作提示。
2. 点敌人：保存它所在的优先位置，并对这只敌人发出当前集火指令；从下一次可发动的行动生效，不重置攻击/冷却、不改变已经在飞的攻击。
3. 当前目标有效时保持攻击；它死亡或失效后，在“优先位置及邻位”的合法存活敌人中按五种策略排序；附近都没人时，全场按同一策略选敌，防止站着等。
4. 位置偏好一直保留；已锁定其它敌人时，新的补怪不自动抢走目标。等下次重新选敌再应用位置偏好。切换策略、清除偏好或再次手动点怪时允许从下一次行动重新评估。

第 2 步点中敌人当前强制集火、以及第 3–4 步保持到失效的细节为推荐，需用户查看图后确认；用户已经确认的是持久位置/附近优先与死亡后自动使用保存设置。此处不强行把优先中心排在邻位之前：先得到区域候选，再按自动策略筛选。

界面提供小按钮“清除偏好”，只清空位置偏好、保留所选策略。英雄下方数字为**当前实际攻击目标位置**，例如 `目标 4`；无人可打显示 `—`。左下另显保存的优先位置，避免“优先 4、当前打 2”时误以为出错。怪物新实例与旧实例位置相同也不能继承旧弹道伤害。

## 四、选人、指挥与查看信息不冲突

选中英雄常驻，但“等待点敌人下指令”只在点击英雄后进入一次；指令提交后退出该状态。这样之后单独点击敌人可仅查看右下资料，避免任何查看都偷偷改指令。右下另留小的“仅查看”入口；Esc、点击空白或切到其它面板可取消未完成的下令状态。键盘/触屏实现时也应有明确提示，不用隐藏的组合键作为唯一入口。

选择英雄、切策略、查看常驻敌人面板默认不暂停。技能/装备详细说明打开仍沿用已有暂停规则；普通选人不和说明暂停绑定。示意图中的金色表示当前选中英雄/敌人，实际目标用数字及选中英雄的一条短暂连线提示，不绘制全队常驻交叉线。

## 五、挑战传送带与刷新列表

传送带展示的是**可选的敌方挑战**；其中“英雄”按敌方英雄挑战者理解，不是我方招募、不占我方五人名额。此理解写入说明，若用户另有招募意图需单独设计。

```text
传送带候选（可忽略） → 点击加入 → 待入场列表
→ 到补怪时刻且推荐位置有空位 → 入场 → 击杀后发奖励
```

每张卡展示：名字/类别、威胁提示、推荐位置、奖励预览、剩余展示时间；点击后卡片明确变为“已加入”，不能重复入队。传送带候选自动移动或更新不代表自动接受挑战，未点击者离开不发奖也不直接进场。动画与候选期限跟随游戏模拟暂停。

待入场列表与候选带分开，避免玩家误以为点击后立即出现。推荐已接受的挑战占用下一批的一个正常入场名额，有合适空位才进入；它不消耗金币，也不在接受时给奖励。较高奖励优先沿用现有击杀金币，特殊掉落稍后随内容设计，不因新增挑战自动加入装备背包。

待入场数量、候选有效期、是否可撤销接受、挑战是否替换/增加原本刷新预算均需定稿；图中队列容量与奖励数字只是展示。首版推荐“同一批里优先排入、使用正常场上名额”，不无限增加同时在场怪物。关卡时间结束后默认沿用停止补怪、清场的流程，但尚未入场的挑战如何处理需确认，推荐取消未入场请求且不奖励，已入场必须清除；见 Q006。

[查看概念图](design/battle-v2/battle-v2-concept.png)（实际 PNG 1672×941，非游戏截图）；比例/占位差异见 [图稿说明](design/battle-v2/README.md)。

| 区域 | 内容 | 目的 |
| --- | --- | --- |
| 顶部约 5% | 层数、时间、金币、暂停 | 常驻关卡状态 |
| 上方约 14% | 挑战传送带 + 分开的待入场列表 | 选风险、看奖励与入场等待，不遮挡战场 |
