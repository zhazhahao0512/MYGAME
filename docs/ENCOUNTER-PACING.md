# R062 · 怪物耐久、补满速度与即时挑战

2026-10-20（北京时间）。基线b2df1e7，当前为本报告所在实现提交；[D033](decisions/D033-attack-colors-and-encounters.md)记录用户澄清。具体系数是可调整试玩值。

## 当前参数

- 开局五敌；普通补怪由每6秒最多2只改每2秒最多5只，只填空位。40秒到点停止补怪并清场，不移动或替换活怪。
- R049固定楼层生命基础×1.5、攻击基础×1.1，双抗不变；首领生命倍率3.2→3.8（相对旧首领总生命约×1.78）。不按玩家装备/等级追涨，无锁血或最低生存时长。
- 精英铁卫/深渊咒术师/游侠挑战者分别相对铁卫/咒术师/灰爪约3倍生命、1.8倍攻击，奖励180/210/250金币不变。特殊技能仍沿既有配置，非单纯完整复制普通怪。
- 有空位点击立即生成挑战，推荐位优先、最近其它空位兜底；满员禁用，无等待队列。过期/清场/重复接受二次校验，免费接受、击杀发奖一次；普通补怪时刻不重置。
- 每级击杀阈值16→12。只提高耐久的第一候选让通关等级降到12–14，主动挑战2组均在20层失败；配套经验后恢复可用技能进度。旧档等级不降低，下一次结算可能补级。

受伤至死从首次实际生命/盾伤开始，包含范围伤害后等待集火、反复转火和清场，**不是五英雄持续集火DPS**。长尾仍明显，需继续关注后排清场。当前基线普通阶段已经平均4.27敌，不等于复现用户服务器上的版本；更不能宣称全程永远五敌，计时结束后仍应逐渐清空。

金币单价和装备价格未变，但击杀减少使普通整局收入中位降低约17%；这是本轮明确保留的经济影响，下一步需用实际购买/合成与高协同构筑校准。通过这些固定策略不代表最终难度、手机帧率或服务器已上线。
