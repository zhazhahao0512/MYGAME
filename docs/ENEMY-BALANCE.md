# 测试版怪物曲线校准 · R049

2026-10-20（北京时间），基线 4639cd4。用户反馈怪物生命过低、被英雄瞬间秒杀。本轮修复已实现测试内容；以下为可调整工作参数，不是最终难度或所有构筑的平衡定稿。

## 问题和实际改动

R048 英雄初始攻击已为约 60–87，但怪物还使用早期 `(100 + 10×层数)×类型倍率` 生命、`1.5×层数` 双抗。旧首领只有 `260+35×层数` 生命。原来的“完整20层通过”只能证明流程可走，不代表战斗有足够交互时间。

新增 `src/combat/enemies.js` 集中管理固定楼层曲线。令 f 为层数：

- 开局系数 `0.65 + 0.35×min(1,(f−1)/3)`，照顾前四层从2人到5人的招募过程。
- 基础生命 `(440 + 120f + 1.5f²)×开局系数`；普通/挑战怪乘现有类型生命倍率，首领乘3.2，最后取整。
- 普通攻击基础 `6 + 1.5f + 1.5×max(0,f−4)`，乘类型伤害倍率；首领乘1.4。
- 双抗 `10 + 1.5f`；攻击频率、技能、精准/闪避与类型差异仍沿用原配置。
- 每级击杀阈值由20改16，集中为 `RULES.killsPerLevel`。原因是耐久提高后击杀供给下降；不会降低旧档等级，下一次结算按原 `max(原等级,计算等级)` 补齐，旧档可能获得补级和待分配点数。

| 例子 | 旧生命 | 新生命 |
| --- | ---: | ---: |
| 1层铁卫 | 132 | 438 |
| 4层铁卫 | 168 | 1133 |
| 20层铁卫 | 360 | 4128 |
| 5层首领 | 435 | 3448 |
| 20层首领 | 960 | 11008 |

怪物只看楼层和类型，不跟随玩家等级、装备或实时DPS自动抬高数值；没有锁血、伤害上限、强制最低存活时间。强构筑仍可缩短击杀时间。保留40秒后清场、每6秒最多补2个、死亡留空和5/10/15/20层首领；不增加新敌人技能，不改英雄或装备面板。

## 实际Battle对照

使用同一个真实Battle引擎，默认20ms步长。8个固定种子，每版本160场真实流程关卡＋80场固定队伍快照，共480场。完整结果摘要和逐关队伍/装备/等级/收入见 [JSON](enemy-balance-results.json)。原始逐怪首次受伤/死亡/命中次数可按下述脚本重建到忽略目录。

**计时口径**：从第一次实际受伤到死亡；一击致死记0秒，没死的标截断且不混入击杀时间。范围伤害可能很早擦到后排，因此长尾包括暂未被集火的等待；不把这一口径解释成每只怪都被全队持续集火的时间。固定快照保持队伍、等级、技能点和装备一致，整局比较则允许经验/收入自然反馈。

| 8种子20层实际旅程 | 旧曲线 | 新曲线 |
| --- | ---: | ---: |
| 普通怪受伤至死中位时间 | 0.04秒 | 4.32秒 |
| 普通怪1秒内击杀 | 2549/2688（94.8%） | 0/2089 |
| 单关总时长中位数 | 40秒 | 47.96秒 |
| 单关击杀中位数 | 17 | 14 |

默认策略只选第一个招募/宝箱，有钱则按顺序填空装备槽；不刷新、不合成、不替换，不请求额外挑战，不操作集火。真实使用招募/购物/升级与结算，不修改英雄属性、不伪造胜利。原有种子1/7/42的20层回归也保留。

固定队伍为磐石/岚牙/烬语/青禾/赤刃，1层仅前两人；等级取1/3/6/10/15。带装快照1层一把白剑，4/8层两件，12/20层四件蓝白装备，详见脚本。4层起队列加入三类挑战：

| --- | --- | ---: | --- |

| 4层 / 3级 | 0.12→2.54秒 | 4.44秒 | — |

| 20层 / 15级 | 0→12.90秒 | 8.02秒 | 0.58→9.82秒 |

20层裸装普通怪20.9秒、首领13.98秒；前者含范围伤害先触碰、后集中打的时间，不能与挑战怪直接视为相同集火条件。总体普通怪P90为24.6秒，说明还有长尾；本轮不是把所有怪固定成4秒。8种子全部已生成敌人最终死亡，无180秒截断；样本规模有限，不能宣称任意队伍/旧高装档都不会秒杀或都会通关。

## 连带影响与限制

第一候选同时大幅提高攻击，导致前4个种子在首层失败；随后使用上述开局系数和较缓攻击爬升修正。仅加耐久时，首批4个种子通关约12–15级，故加入16击杀/级后再完整复测。没有降低新耐久或篡改测试胜负来掩盖失败。

单怪金币、物价、宝箱和刷新费不变。击杀减少使整局收入下降约22%，是实际代价；当前8种子的真实购物策略仍通关，每层宝箱仍提供一件装备。新曲线下实际合成/更换和高协同紫装、主动多次挑战、不同技能加点仍需后续试玩，而不是立即随意加强装备。七名旧英雄技能仍是示例，后续正式技能上线要重测。
