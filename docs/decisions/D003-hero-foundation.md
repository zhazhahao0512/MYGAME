## 职业与路线

- 五个位置是队伍容量，不对应五个固定职业槽。大类为坦克、战士、法师、刺客、射手、辅助。
- 职业描述职责，细分标签描述实现方式，伤害类型独立；刺客可以造成魔法伤害，不将物理/魔法与职业绑定。
- 同一英雄可以依靠装备、强化和队伍搭配形成多条路线，允许混搭，不预设不可更改的职业分支。英雄仍须有核心特色与短板。
- 血量、单抗、减伤、控制等坦克方向是差异化示例，不是已设计完成的英雄名单；六类也不要求各只有一个模板。

## 初始属性与成长

每名英雄分别设计以下八项的初始数值和成长，不要求与同职业英雄相同。生命回复、法力回复必须纳入基础属性；某项成长可以为零，但不能漏记。允许合理的非整十数值与小数，不为凑预算机械改成相邻数字。

| 属性 | 初始值设计 | 成长设计 / 单位 |
| --- | --- | --- |
| 生命上限 | 英雄独立 | 点/级 |
| 生命回复 | 英雄独立 | 点/秒，每级增量独立 |
| 法力上限 | 英雄独立 | 点/级 |
| 法力回复 | 英雄独立 | 点/秒，每级增量独立 |
| 攻击力 | 英雄独立 | 点/级 |
| 基础攻速 | 英雄独立，次/秒 | 分别配置等级攻速加成；百分比口径与装备对齐 |
| 物理抗性 | 英雄独立 | 点/级 |
| 魔法抗性 | 英雄独立 | 点/级 |

法术强度仍展示为属性，但所有英雄初始值为 0、每级成长为 0，只能通过装备增加。法强不直接提高普通攻击伤害。同等属性金币预算下，装备法强点数应高于攻击力点数；具体比率尚未确定，见 [Q004](../open-questions.md#q004)。不能把参考 LoL 解释为已经采用其具体数值或价格。

暴击率不作为英雄默认天生属性或等级成长，初始为 0。技能急速、吸血、穿透、韧性、增伤、直接减伤、治疗/护盾增强等不默认纳入八项成长；特殊英雄机制需另外明确设计与估价，不能免费加进面板。法强的装备来源限制不能被泛化的“强化可改变路线”绕过。

精准 95、闪避 0 继续遵守 [ACCURACY-DESIGN](../ACCURACY-DESIGN.md) 的已确认规则，不因八项个性化属性清单而删除。不得恢复已被替代的专注/移速设计；独立闪避上限冲突仍见 [Q001](../open-questions.md#q001)。

## 攻速与估值口径

用户已否定“所有英雄基础攻速均为 1 次/秒”，基础频率和成长都要做出差异。本窗口讨论沿用如下计算口径，未来实现时须与装备规范统一验证：

```text
实际攻速 = 英雄基础攻速 × (1 + 等级攻速加成 + 装备及其它普通攻速加成之和)
```

公式内百分比使用小数，成长按百分点累计；普通加成不逐件乘当前攻速。0.83、0.96、1.07、1.18 次/秒仅为讨论示例，不是已批准的英雄配置。

基础攻速影响装备与攻击触发收益，必须计入平衡；装备“额外攻速每个百分点”的价格不能直接当成基础频率每 0.01 次/秒的通用价格。基础攻速估值仍待校准。

## 预算、替代关系与未决边界

- 用户已接受以同一属性金币换算表比较英雄初始属性、成长和装备。初始预算与成长预算只用于比较，不是英雄购买价，也不保证等预算实战等强。
- 本窗口先前参考装备 V2 得到约 7,000 金初始已定价属性、300 金每级成长的起步预算；它不是完整英雄预算，不覆盖当时未定价的法力、回复、技能/被动及不同基础攻速。用户随后要求英雄面板和成长差异化，不能强迫每人精确相等。
- 上述数字是沿用 V2 的历史参考。同步后的仓库已记录外部装备 V3.3，但全文尚未统一入库；不得把 V2 宣称为现行最新装备规范，亦不将示例预算认定为最终平衡值。下一步先按最新可核实装备规则复算，见 Q004。
- 早期“235 金初始、8 金成长”估价已弃用；共同基础攻速 1 次/秒方案被英雄独立基础攻速替代；早期英雄初始/成长法强方案被统一 0 与装备来源限制替代。
- 法强、法力与两种回复等属性价格、八项完整成长表、基础攻速估值、具体英雄技能和技能随等级增长数值均未完成。法系技能基础效果随等级提高只是此前建议，没有因法强零成长而自动批准一套新公式。
