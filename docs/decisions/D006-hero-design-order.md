# D006 · 英雄设计顺序与动画后置

- 状态：已确认设计顺序，2026-10-19（北京时间）；没有游戏代码实施。
- 确认依据：用户本轮明确“先设计基础数值和成长数值，不一定是整数的，然后是技能，包括英雄分类之类的也要设计，动画什么的等基础玩法能流畅游玩再设计”。
- 决定：先逐英雄设计八项初始属性与成长；允许小数、合理非整十数值，不套相同面板。随后设计技能，并完善英雄分类、细分定位和多路线；动画等表现设计等基础玩法能流畅游玩后再开展。
- 与 D003 的关系：补充执行顺序，不替代 [D003](D003-hero-foundation.md) 的六类多路线、独立基础攻速、零初始/成长法强且只由装备增加、默认零暴击等规则。先做数值不是永久锁死数值，技能设计与实战可以反向校准。
- 当前阶段：基础/成长数值设计。分类仍在英雄设计范围内，不因动画后置而一同推迟；暂不制作具体英雄动画或扩充表现方案。
- 数值表达：初始值、每级增长和成长单位分别列出；生命/法力回复使用点/秒，基础攻速使用次/秒，攻速成长区分百分点与绝对频率。每个英雄与同职业英雄都可不同，不为差异而随机添加无意义小数。
- 最新参考：本轮同步到装备归档 `0bf3ae4`，已读取 [D005](D005-equipment-foundation.md) 和 [装备工作稿](../EQUIPMENT-DESIGN.md)。法力、回复与法强等已有白装获取单价工作值可用于下一轮试算；基础攻速估值和完整成长预算仍待校准。D003/R017 中“最新装备全文未入库”是当时历史状态，不再作为当前缺少资料的理由。具体装备工作值不因此自动升格为最终平衡值。
- 实施/验证边界：本轮没有确定新的英雄面板、技能公式、动画方案或流畅性验收结论；只记录顺序。实际检查和提交状态见 [PROGRESS R020](../PROGRESS.md#changelog)，Page 待同步。
