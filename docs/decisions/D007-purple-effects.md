# D007 · 首批攻速紫装与同名被动唯一

- 日期：2026-10-19（北京时间），R021。
- 状态：已确认装备设计；五个名称为依用户要求完成的设计产出。无游戏代码改动，未实战验证、未部署。
- 确认依据：用户明确接受上一批紫装，并确认固定/临时攻速相加、重复装备基础属性可叠但同名被动只生效一份、连击附伤受护甲减免而不能暴击/吸血/再触发攻击特效；要求每个不同效果命名，并参考英雄联盟思考攻击特效。

## 决定

1. 接受疾风双刃、连击长弓、猎风长弓、血潮双刃、守望双刃、鏖战长枪这六件方案，沿用 [装备设计表](../EQUIPMENT-DESIGN.md) 的原属性、效果数值、总价与配方，不另调价或加强。
2. 固定与临时额外攻速按百分点相加，再作用于英雄各自基础攻速。鏖战长枪叠满本件提供 +36%，不把它解释为全英雄都使用相同基础频率。
3. 重复装备基础属性可叠；同名被动在同一英雄上仅生效一份，不限制不同英雄各自携带。不同机制分别命名，名称与稳定效果标识对应。
4. 连击长弓附伤称为攻击特效，仍是受护甲减免的物理伤害；不能暴击、吸血或再次触发攻击特效。命名不额外增加伤害类型或改变其它伤害/闪避规则。

## 本轮命名结果

连击长弓—三重打击；猎风长弓—乘风；血潮双刃—血性；守望双刃—战意护盾；鏖战长枪—穷追。疾风双刃为纯属性装备，不设被动名。登记及触发说明见 [ATTACK-EFFECTS-DESIGN](../ATTACK-EFFECTS-DESIGN.md)。用户要求分别命名，但未逐字指定这些名字；本记录不伪称名字来自用户原话。
