# D011 · 技能加点限制与岚牙三箭去法强

- 日期：2026-10-19（北京时间），R026。
- 状态：用户指定规则已确认；新的技能 3 伤害数值为可调工作值，未接入游戏。
- 确认依据：用户明确二级必须点不同技能、6 级之前最多点到三级、之后解除限制，并要求 3 技能不要法术加成、询问伤害是否偏低；异步答复确认“普通技能解除限制，大招仍在 5／10／15 级升级”。

## 已确认规则

1. 英雄 2 级的技能点必须投入不同于第 1 点的普通技能，不能同技能二级。
2. 英雄 3–5 级，普通技能等级最多三级；英雄 6 级起不再有额外英雄等级门槛，但技能本身仍最高四级。
3. 大招在英雄 5／10／15 级分别解锁一级／二级／三级；不随普通技能解除门槛。
4. 岚牙 3 技能移除法强加成；该要求限于 3 技能，1 技能既有法强系数保留。
