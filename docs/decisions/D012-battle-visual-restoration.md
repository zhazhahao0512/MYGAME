# D012 · 按概念图修正战斗视觉

- 日期：2026-10-19（北京时间），R028。
- 确认依据：用户指出生成概念图与实作差别过大，R027 对照后承认角色比例、信息大小、阵营配色、边框和环境表现缺失；用户随后回复“可以 开始”。本轮获得视觉修正授权。
- 范围：保留 V2 功能，修正紧凑信息卡、卡内血蓝/行动进度/目标号、青红阵营与金色选择、挑战箭头及卡片层次、左右详情排版；加入地牢环境素材。头像、装备、技能仍可用文字方框占位。
- 验收：使用实际 2560×1440 浏览器截图对照概念图，同时检查 1440×900 和既有手机横屏的可读性/可点击性。功能测试通过与用户视觉验收分别记录，不能将新生成图片当成实际页面截图。
- 边界：精准/闪避接入继续暂停；不改变伤害、刷怪、经济、锁敌、英雄或装备数值。概念图中的错误属性示例不照抄，继续主要/次要属性分类；不承诺逐像素复刻生成图的所有纹理。
- 替代：接续 D009 的视觉实现，修正 R024 功能完成但视觉偏离的问题；原概念图及 R024 截图保留用于比较。D011 英雄加点等并行结论原样保留。
