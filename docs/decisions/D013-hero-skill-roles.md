# D013 · 英雄技能分工与质变强化余地

- 日期：2026-10-19（北京时间），R029。
- 状态：用户明确的英雄设计原则已确认；不代表批准修改游戏源码或具体平衡数值。
- 确认依据：用户要求一个契合英雄主要方向的技能、一个辅助该方向的技能、一个适度补全短板的技能；短板不能过大、长板不能过强，因为后续还有海克斯等质变内容，需要避免组合失控。

## 已确认原则

1. 三个普通技能要有可辨认的职责：核心玩法、配合核心、适度补短板，不能三个技能都不分职责地堆同一种强项。
2. 基础英雄需要可正常发挥，短板不过分；又应保留可被针对的弱点，不把补短板做成全面补齐。
3. 强项不能在基础英雄阶段就推到过高水平，要把装备、海克斯等后续质变纳入平衡考虑。
4. 继续遵守 D003 的多路线原则；技能分工不意味着每个英雄只能使用一种装备或输出路线，也不要求每个技能都提供所有属性加成。

## 岚牙映射与分析边界

- 1 淬锋箭：提供可重复的普攻附伤，建立攻击特效方向。
- 2 疾弦：用攻速与命中减自身冷却配合高频攻击。收益应来自核心普攻与特效循环，不再顺带包办回复、免控、护盾等完整生存能力。
- 3 三向追猎：补有限多目标输出及短时精准／闪避；保持最多三不同目标、4秒增益、不把余箭集中于单体、不自动携带特效。具体边界沿用V0.2工作稿，仍属可调设计。
- 大招是现有核心玩法的10秒爆发；同时维持1/2并提高真伤倍率，后续评估海克斯时应重点看多项增益相乘的结果。被动与大招也参与整套预算，不能因为三普通技能有分工就不计它们。
- 上述编号是岚牙的映射，不将用户的“一个核心／一个辅助／一个补短板”擅自扩成所有英雄必须固定编号。

[DPS分析](../heroes/LANYA-DPS.md) 同时报告单体、三目标、短爆发、整关、蓝耗与防御，避免仅按最高DPS挑所有技能。辅助技能升级的DPS收益较高不自动违背分工，须看它通过何种机制产生收益；多目标／防御价值也不能当成免费赠送。

## 后续工作建议（非额外已定数值）

- 评估新增质变时，在同装备／等级条件下额外测试攻击次数、多目标特效、附伤倍率、冷却或蓝量改变，区分单个强化与组合结果，尤其注意是否递归触发。
- 保留窗口、目标数、触发资格、资源消耗等可调约束；不能把冷却带来的自然空档忽略，也不能用无限蓝木桩替代实际续航。
- 不在本轮规定海克斯强度百分比、全局攻速封顶或停止固定成长；D008的持续面板成长不变。需要调低或重新分配技能数值时另列具体方案，不把风险判断冒充已调平衡。

本轮新增原则记录和设计分析，没有改变岚牙V0.2数值、装备或游戏实现。证据和交接见 [R029](../PROGRESS.md#r029)。
