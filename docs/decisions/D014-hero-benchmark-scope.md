# D014 · 统一英雄测试标准的设计范围

- 日期：2026-10-19（北京时间），R031。
- 状态：用户明确要求设计统一方案；具体参数为首版工作稿，尚未接入游戏。
- 确认依据：用户要求每个英雄共用输出/承伤测试，覆盖打一个、三个、五个目标，打不同类型木桩和被不同类型木桩攻击，用于比较英雄强弱、成长曲线与装备增幅。

## 已确认范围

1. 统一条件与报告格式，使不同英雄和同英雄不同构筑可以比较。
2. 输出与承伤都覆盖1／3／5目标或来源，区分目标防御类型与敌方攻击类型。
3. 覆盖成长及装备增幅；遵守D003/D008的多路线、差异化面板、法强只由装备增加与固定成长不停。
4. 继续按D013审视核心、配合、适度补短板及质变余地，不把所有职业强制设成同一DPS。

## 本轮方案与边界

[HB-1.0方案](../heroes/HERO-BENCHMARK.md) 提出固定资源/站位/随机种子，十类防御木桩、八类攻击源，输出潜力/有限击杀/换靶/混合战斗，静态/完整固定压力/有限实战承伤，以及辅助陪测、成长、装备与强化敏感性。

15级3000生命/50双抗、200原始压力DPS、时间窗口、预算档与缩放曲线等是本轮建议参数，不能把设计范围授权写成用户逐项确认或游戏实施批准。它们不改变现有敌人、关卡、补怪时间、英雄或装备数值，不新增全局成长/攻速上限。

[参数JSON](../heroes/hero-benchmark-v1.json) 与 [核验脚本](../heroes/check-hero-benchmark.py) 只提供可复用配置和参考算式检查，不是已实现的英雄战斗测试器。旧岚牙R029分析保留独立版本，不能不重跑就纳入HB榜。Q001/Q009触发边界尚未确认时，须标候选或不支持，不以测试器默认值替代规则决定。

无替代旧游戏决定。实施与参数校准接续 [Q011](../open-questions.md#q011)，完整战力预算仍见Q004；交接与验证见 [R031](../PROGRESS.md#r031)。
