# D020 · 默认全托管与逐技能模式圆钮

- 日期：2026-10-19（北京时间），R041。
- 确认依据：用户明确“全托管优先”，每个技能独立，在技能图标右上角加小圈圈，点击切换“托管释放、自动释放、点击释放”。
- 状态：交互设计已确认；本轮更新设计文档，无游戏代码改动。

## 已确认要求

1. 默认所有主动技能采用托管释放，作为主要使用方式；每个技能可独立切换，不统一绑到英雄全局模式。
2. 每个主动技能图标右上角增加小圆形模式切换按钮，点击改变该技能模式。
3. 对外名称统一为“托管释放／自动释放／点击释放”；语义继续D019的智能安排、合法即用、玩家下令。

## 设计细节与替代关系

[V0.3施法设计](../heroes/SKILL-CASTING-DESIGN.md)按上述顺序循环，建议圈内用“托／自／点”识别，点击圆钮只切模式，技能主体继续查看说明、独立按钮负责释放。保留R007暂停契约；圆钮触控区、提示、保存和迁移细节为本轮设计，待实现验证。
