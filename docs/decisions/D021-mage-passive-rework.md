# D021 · 余韵定时技能附伤与导流参与击杀回蓝

- 日期：2026-10-19（北京时间），R042。
- 状态：用户明确要求的机制方向已确认；周期、伤害、参与窗口、15蓝建议和2200报价为本轮可评审参数，未实施游戏。
- 确认依据：用户否定余韵近常驻法强，要求每隔几秒强化下次技能造成额外伤害；认为导流每秒1蓝过弱，随后进一步明确改为每参与击杀一个怪物回蓝，询问约30是否合理。30是待判断候选，不冒充确认数值。

## 现行设计与取舍

1. 余韵移除临时法强，建议开场就绪、消费后12秒独立冷却；下一次伤害型主动只对主目标附加25＋5%法强魔法伤害。一技能一次、不按群体/多段增加，沿本次主段命中并受魔抗，不暴击/吸血/递归特效。
2. 导流移除施法后加回蓝，改成击杀/伤害助攻恢复；首版建议每只15蓝，无额外冷却。死亡前6秒有效生命/盾伤建立参与，同怪每英雄只一次，溢出丢弃。单首领死亡前无此收益，是清怪续航方向的代价。
3. 40秒、50蓝技能的给定击杀时间表中，6–8次参与下，15蓝相对关闭被动多支持2–3次施法；30蓝则4–5次。群怪密集且多人参与时，30更容易削弱法力约束，故本轮不推荐作为无冷却紫装值，后续高阶另核算。
4. 三件基础属性/材料和辉光/流转售价保持；澄源建议1900→2200、合成费500→800，效果预算200→500。500是对既有150–450建议区间的本件复审例外，占总价22.73%；不改变白蓝单价或全局预算。
