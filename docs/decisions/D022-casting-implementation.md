# D022 · 逐技能三模式与对应UI接入

- 日期：2026-10-19（北京时间），R043。
- 确认依据：用户明确“开始接入，是不是要调整对应的UI？”，授权实施D019/D020三模式及其操作入口。
- 实施范围：当前可玩英雄的逐技能托管/自动/点击模式、右上圆钮、1–4显示、独立释放与快捷键、法力策略/短指令/保存迁移；不是仅画开关。岚牙数值、新装备、完整技能升级和新精准不在本轮迁移。
- 实际行为：[COMBAT](../COMBAT.md)的R043记录算法和资源边界，[交互规范](../UI-INTERACTION-DESIGN.md)记录模式圆钮及暂停；[施法V0.4](../heroes/SKILL-CASTING-DESIGN.md)保留尚未落地的英雄专属模板。
- 首版取值：8秒准备、35%救急生命、2秒近期受伤、25%同层同用途计划更换、1.5秒单条点击等待；按原生20ms行动步评估。规则是已授权方案的可调实现参数，不冒充用户逐项指定或平衡定稿。
- 保存：按英雄技能存三模式，旧档缺字段/非法值默认托管，忽略旧auto大招开关；跨关/换位保持，战斗中读档仍重开该关。
- 替代关系：接续D019/D020，替代原型R专用开关和四技能固定自动；保留说明查看、暂停叠加、目标/弹道快照和其他玩法。技能定义可读取rank/ranks，但正式技能加点系统仍待后续。
- 验证与边界：检查/截图及发布状态见[R043](../PROGRESS.md#r043)与[实图](../design/casting-modes/README.md)。功能验证不等于所有英雄策略最优、手机真机验收、用户视觉认可或服务器已部署。
