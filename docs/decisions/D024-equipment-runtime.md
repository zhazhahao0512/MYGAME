## 实施范围

1. `src/equipment.js`登记12白、21蓝、14紫的固定ID/属性/价格/材料/合成费、11个被动名字及说明。新商店/宝箱仅抽这47件，不再按品级缩放旧模板。正式品级白蓝紫红橙；红橙无正式条目，暂不生成。旧存档绿装/橙装及旧示例被动保留兼容。
2. 装备详情显示反向升级路线、配方、缺口与合成费。只在商店合成，使用全队已穿戴的不同材料实例；选择的材料槽接收成品。确认窗列出持有人和槽位，确认时重新校验UID、配方、阶段与金币；只扣合成费，不出售材料、不生成背包。重复材料须两件不同实例。
3. 固定与临时额外攻速使用同一percent池，作用于每名英雄基础频率；普通属性叠加，同effectId被动每英雄仅一份。新旧装备混用时旧装备保留原平加规格。新英雄成长/技能攻速须接相同普通百分比池，最终乘区另处理。
4. 普通怪/首领/挑战金币与刷新费统一换为旧值的10倍：普通怪30，首领150，刷新80起每次+40。装备设计价格保持250–2200。此为实施时解决旧16–58金币价格单位不匹配的试玩经济选择，非20层经济已定稿。存档version1→2只迁移一次金币、累计收入、上一关收入和旧物品价格；装备属性不改，保存键保持，正式条目按目录恢复，重复持有UID拒绝。

## 本批局部结算决定

- 三重打击共用普攻命中，不另抽命中/暴击；发射时读取总AD和目标护甲等减免，普攻本体结算后仅打仍存活的原目标。禁止普攻和全能吸血、不产生hit/critical命中特效事件；正常damaged/死亡与导流参与保留。计数跨目标保留，盾命中算一次。来源已死亡的在途攻击及已绑定附伤仍结算；乘风/穷追/回流/战意护盾这些自身收益要求来源存活。
- 血性在普攻落点、伤害和吸血结算前读当前HP严格低于50%；只给该次本体额外3%吸血。其余吸血仍读发射快照。背水动态修改后续行动AD，不追改在途快照。狠厉与卸力在本体发射快照中各应用一次。
- 战意护盾独立记录剩余量与到期tick；刷新补至30而非累加，承伤先消耗该3秒盾再消耗既有无期限技能/旧装备盾；到期仅删除自身剩余量。这是当前来源组合的局部顺序，不冒充未来任意多盾排序或全局四伤害类型迁移。
- 穷追命中叠层/刷新，切换主要目标立即清空；已飞往旧目标的攻击不能重建旧目标层数。未命中不刷新。乘风/回流仅刷新一份。
- 余韵在成功释放构造首段时绑定一次；沿现引擎释放/发射快照读取该段AP，多目标技能取既有目标列表首位为主目标。12秒模拟时钟独立冷却；闪避/目标死亡不退、不转移；释放前打断或无目标不消耗；禁止两类吸血和命中特效递归。
- 导流按实际HP/盾损失记英雄归属及最后伤害tick，死亡前6秒含边界；本人或明确ownerId链的伤害可参与，纯治疗/护盾支援不算。每个唯一怪物死亡只结算一次，存活合格英雄各回15，封顶无溢出储存。现引擎无正式召唤物内容，但归属路径有测试。
