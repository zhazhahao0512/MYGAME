# D032 · 战斗、商店、宝箱统一风格与装备全名

- 日期：2026-10-20（北京时间），R061。
- 确认依据：用户接受R055战斗图、R057同风格商店图，明确“装备要显示全部名称不要只显示一个字，开始修改代码，宝箱页面呢？风格要统一”。
- 已授权：以暗蓝底、象牙白文字、细金边及金色选中统一战斗HUD、商店与宝箱；商品和已穿戴槽位显示完整名称，允许换行，不依赖悬停才见名称；说明/替换/合成中的装备名称同样保留。
- 宝箱：继续与商店及队伍同页，免费三选一、单项刷新、穿戴或出售后切换商店；奖励未处理前不能下一层。没有新增仓库、购买确认步骤或独立开箱动画。
- 商店：四商品、五英雄四槽；选择条显示真实价格/预估余额；指向或聚焦目标槽读取模型预览属性变化，选择/预览不扣款，空槽直接穿戴，占用槽局部确认。金币、材料与属性均从现有模型读取，不复制概念图的示例数据。
- 战斗：底部英雄/敌人详情约2:1、紧凑挑战条、完整装备名；沿用既有背景和Phaser场景，保留技能独立模式/说明/释放、目标指令及主要/次要单按钮等高切换。R059/R062动画与节奏由其窗口负责。
- 范围边界：本轮实施展示与浏览器验收，不修改伤害、装备价格/配方、英雄技能、成长或存档规则。图稿是方向参考，不等于逐像素要求；手机以完整名称、可点击与不横向溢出为先，允许纵向滚动。
- 结果/验证/发布以[PROGRESS R061](../PROGRESS.md#r061)与[实际页面](../design/ui-runtime/README.md)为准。源码提交和推送不代表服务器已部署。
