# D033 · 角色攻击配色、快速补满与挑战即时入场

- 日期：2026-10-20（北京时间），R062。
- 用户要求：攻击动画与角色同色，近战和远程有区别；加强怪物，减少长期多打一；传送带挑战点击直接上场且明显强于普通怪。
- 明确澄清：用户选择“缩短刷新间隔，更快补满敌方”和“有空位时立即入场；满员时按钮禁用”。不再沿用D009的慢批次/等待队列。
- 入场：普通怪仍死亡留空、按位置补怪，不移动活怪。挑战有空位即进入，优先推荐位，再选距推荐位最近的空位；满员、过期、清场或重复点击均不能接受。免费接受，击杀后才发一次奖励，不替换活怪、不排队或取消已入场怪。40秒后停止入场并清场不变。
- 表现：角色名字与攻击使用角色配置色；近战普攻蓄势并于真实命中时斩击，远程普攻箭形飞行，伤害技能环形飞行。伤害、护盾、治疗等结果仍用原语义颜色；减少动效仍保留必要攻击提示。
- 工作参数：普通补怪6秒/最多2只改2秒/最多5只；基础生命×1.5、攻击×1.1，首领生命倍率3.2→3.8；挑战相对对应普通类型约3倍生命/1.8倍攻击。击杀升级16→12以配合减少的击杀供给。这些是实现与对照模拟选择的可调整试玩值，**不是用户逐项指定的常数**。
- 取代关系：仅接续D009刷新/挑战边界与R049曲线/经验速度；保留五策略、持久位置偏好、唯一实例保护及现行精准/伤害/装备规则。R059减少动效保留攻击信息继续有效，形状/颜色接续本轮。
