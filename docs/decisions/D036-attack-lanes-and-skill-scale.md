# D036 · 站位弧线分层与技能临时尺寸

- 日期：2026-10-20（北京时间），R065。
- 依据：用户要求双方出手位置5/4/3/2/1的弧线高度依次递减，不要重在一条线上；解释后补充“技能就先用放大三倍的代替，大招放大五倍”。本轮接入该连续请求，不改角色卡片高度或战斗数值。
- 轨迹：飞行普攻与伤害技能按来源站位选固定五级弧高，5最高、1最低，双方同规则；目标只决定落点。选中目标虚线也随来源站位分层。动画只读原start/end tick，暂停冻结，不延迟伤害。
- 尺寸：以同尺寸战场的普攻图形宽高为1，普通伤害技能3倍、4号大招5倍（兼容R标识）。保留当前角色色、远程箭形/技能环形占位；没有制作专属技能美术。倍数是宽高，不是面积或伤害倍率。治疗/护盾等没有飞行shot的技能继续原事件反馈，不虚构伤害弹道。
- 近战普攻：继续R062来源蓄势与真实命中斩击，不将其改为远程飞行；有飞行过程的技能仍遵守分层。
- 可调实现：桌面普攻22px、紧凑14px；弧高按可用顶部空间和最大5倍图形留边，五级等距；小屏空间较少时压缩层距。保留96在途对象预算，不增加粒子数。减少动效保留作为辨认依据的五层轨迹，关闭旋转蓄势/拖尾/光晕/粒子；接续R059/R062“直线降动效”的旧具体实现。
- 边界：不改单位/技能/装备/命中/经济或伤害结算；新装备R064由另一窗口负责。实现和验证见[UI规范](../UI-INTERACTION-DESIGN.md#attack-lanes-r065)、[R065](../PROGRESS.md#r065)。未核实部署，Page待同步。
