# D038 · 棋盘布阵、怪潮掉装与左右分区方向

- 日期：2026-10-20（北京时间），R070。
- 确认依据：用户明确停止前述移动/框选方案，提出左侧英雄数值、特殊怪传送带、升级和装备仓库，右侧网格对战；上方怪物、下方英雄，可选择放置位置；参考金铲铲攻击模式；取消商店购物，改为怪物爆装备、怪潮与中间休息调整。用户说明为“大概思路”。
- 状态：以上方向已明确；本轮仅讨论、记录，不是完整规则定稿或代码实施授权。现有游戏和线上版本继续运行原规则。

## 新方向

1. 页面左右分区：左侧管理/数值、挑战传送带、英雄升级与装备仓库；右侧主要战场。
2. 战场网格化，敌方上侧、英雄下侧；玩家可以选择英雄布阵位置。
3. 战斗参考金铲铲式自动作战。此前单选/框选手动移动探索停止，不继续实施；普通技能自动执行的简化方向保留，大招手动仅为可选构想。
4. 取消商店购买装备的流程，装备由怪物掉落；引入未穿戴装备仓库。
5. 关卡改为怪潮，怪潮之间有休息阶段供调整。

## 替代与暂不推导的规则

- 新设计替代固定五槽对打布局、上下堆叠主界面、商店购物/刷新、无背包约定。当前源码尚未迁移，历史实现记录与COMBAT继续说明旧版实际行为。
- 不沿用手控移动方案的点地、框选、RTS指令作为新需求。
- 棋盘格形状/尺寸、战中是否自动移动/追击、攻击距离、路径与占格、选敌/精准/弹道如何迁移仍须明确；“类似金铲铲”不自动意味着引入羁绊、买英雄、同名合星、对战玩家。
- 旧20层、40秒刷怪、2秒补满、每轮宝箱和前四层招募需要重新映射；取消购物不等于已取消金币、出售、配方或合成费用。掉率、保底、仓库容量/溢出均未定。
- 现有五英雄、技能和78装备可作为迁移内容基线，不意味着旧站位条件、价格、被动覆盖率或怪物曲线已适配新战场。

## 本轮建议（未确认）

- 桌面约左30%管理、右70%棋盘；左侧分区/切页，避免同时展开全部英雄全部属性。
- 战前/休息时布阵，战中英雄自动接敌、按射程攻击；玩家主要观察与查看信息，大招手动另议。近战自动靠近，远程在射程内攻击。具体移动是首个待确认点。
- 循环：准备布阵 → 一波怪潮 → 掉落自动收集 → 清场后休息 → 分装备/升级/调整 → 下一波。怪潮清场与休息触发边界尚未定稿。
- 战斗中掉落自动进仓库，休息时拖动穿戴/合成；避免战斗中捡装备。通过掉落节奏/容量与溢出规则防止整理负担，但不擅自锁定任何数值。
- 挑战传送带可继续承担主动加难换奖励的作用；战中即时入场或加入下一波、满棋盘如何处理，需结合新出怪方式重新设计。
