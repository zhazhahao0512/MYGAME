2K 实测底栏约 29%，1440×900 约 34%；为文字可读性略高于早期约 24% 的方向值，不宣称已获用户最终视觉验收。背景与装饰层次已接入，但不是逐像素复刻概念图；角色立绘、技能与装备图标继续文字占位。

背景资产为 [dungeon-background.png](../../../public/art/dungeon-background.png)，本轮通过图像生成工具新建的无文字、无角色、无 UI 的地牢环境图，原样复制进入 public/art；CSS 使用它作为背景，卡片、字、血蓝、按钮及动态反馈由实际页面/Phaser 绘制。素材随构建部署，不依赖外部图片服务；原生成文件留在工作区 generated_images，不作为下次环境必须存在的来源。

`node scripts/battle-visual-check.mjs` 可重新生成 2K/1440/844/740 页面截图及 layout.json；已接入 `npm run test:battle`。检查背景实际解码、卡片比例/边界、底栏高度、触屏按钮及次要属性页；视觉还需查看截图，不能仅凭断言通过认为已还原。战斗数值、命中规则、策略与队列行为本轮未改，精准迁移仍暂停。下面保留旧轮次记录。
