圆钮在技能图标右上方独立点击区，托／自／点对应托管／自动／点击；主体仍查看说明。点击模式显示独立释放按钮；灰色表示当前受冷却、目标等条件限制，不是功能缺失。测试图在无敌人等待补怪时可能显示“等待目标”。模式钮与技能主体没有点击区域重叠，四个主动技能显示1–4。

验证命令：

```sh
npm run build
npm test
node scripts/casting-mode-check.mjs
node scripts/battle-interaction-check.mjs
node scripts/engine-check.mjs
```

专项脚本保存四尺寸全部截图与按钮矩形到`test-results/casting/`，验证独立循环、说明暂停中切模式、普通技能手动、重复点击防护、背景暂停、英雄切换和真实存档重载。battle-interaction还执行原有选敌/队列与四尺寸视觉回归；引擎检查保留生命周期、同一Canvas与压力场景边界。截图通过检查不等于用户视觉认可。

手机为Chromium原生触屏模拟，非真机。模式钮手机点击区28px（其它主要按钮44px），底栏174px，740×360战场可见高度因此减少；后续按真机反馈迭代。托管参数为首版，岚牙/正式加点/新装备和精准尚未接入；未宣称所有构筑最优或已部署服务器。
