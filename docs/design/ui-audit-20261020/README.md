## 建议方向

**保留暗色远征题材，把核心体验做成信息清楚、反馈准确的队伍构筑游戏。** 先改善战斗判断、购买/合成比较和成长收益，再补统一的图标/人物资源。当前深绿＋金色菜单已有基调；战斗的写实废墟、复古衬线文字、重金属边框与其它页面差别较大，未来可统一文字角色、按钮等级、边框强弱与间距，不由这次审阅擅自重做背景。

明确三层阅读顺序：即时状态（血量/目标/技能可用）→当前选择与收益→完整规则与次要属性。金色主要承担确认与选中，敌友色承担阵营，品质色承担品级；避免所有边框都与主操作争抢注意力。标题可以保留题材字体，小字号说明/数值优先清楚；统一小数精度、单位与对齐。正文对比和触控尺寸应实际测量，不能凭截图宣称已达无障碍标准。

## 动态、动画、数值和性能如何配合UI

- 优先让动作解释结果：选中→描边响应；装备成功→目标槽短高亮且属性显示差值；升级→点数减少且新等级突出；挑战入队→队列更新。它们比持续漂浮/全屏闪光更能帮助玩家理解。
- 战斗将来重点是“出手—到达—受击”的来源关联，盾伤/生命损失/治疗明确；暴击和重要技能更醒目，普通高频数值合并。完整人物动画待基础玩法稳定后再设计。
- 视觉只消费模拟状态；暂停时同步，关闭效果不改战斗结果。动效时长只是表现参数，不能用动画完成回调决定伤害或扣款。
- UI可以改善数值理解，但不能证明数值平衡。效果增量来自真实模型；不要给未经计算的“战力提升30%”或“推荐最优”标签。经验/怪物变化由R049处理。
- 本轮未测FPS/帧耗时。未来优化应记录指定设备/分辨率/单位数量/特效密度下的帧时间和内存，再决定模糊、粒子、浮字与资源档位。无头桌面通过不等于手机60帧；持续背景特效优先级低。

## 跟AI沟通的可复用方法

一次先改一个页面里的一个关键问题。无需学设计术语，说明“我在这里想做什么、哪里费劲、想看见什么”即可。

1. **圈范围**：页面＋具体区域；引用截图时框选或描述位置。参考图分别说取排版、字体、色彩还是图标，写清其中哪些不适用。D018说明只说“参考这张”容易让AI把局部参考扩为整页风格。
2. **说目标**：例如“选装备时能直接看见给谁穿、获得什么、花多少钱”，比“更高级更炫酷”可执行。
3. **定信息顺序**：必须常驻、点击再看、允许收起各是什么。说明手机/电脑优先及真实尺寸。
4. **先看方案**：先要当前问题、两种布局草图和差别；选一版后先落地一个区域。草图/概念图不是实际浏览器结果。
5. **用状态验收**：空/满、选中/未选中、可用/不可用、长文、鼠标/触摸。要求修改前后同分辨率真截图与点击演示。
6. **反馈写差异**：“这版技能够清楚，保留；下面属性太散，把名称和值靠近，组间距离缩小；先别动其他区域。”每轮保留成功部分，避免含糊的全盘重做。

### 可以直接复制：战斗属性局部

> 使用项目 frontend-design 技能，优化战斗页左下方的英雄数值区。目标是让我快速比较攻击、生存和攻速，而不是读一大段文字。
>
> 参考图只参考属性分组、名称和值的间距与字体层次。背景、传送带、敌方区、技能操作和游戏数值沿用当前版本。保留已确认的主要/次要两页及同高度切换。
>
> 先给两版局部布局草图，说明各自优点，不直接修改代码。方向确定后只实现这个区域。验收2560×1440、1440×900和740×360：文字清楚、不重叠、按钮可触摸，切页不顶高面板。最后给修改前后的同尺寸真实截图。

### 可以直接复制：手机商店

> 使用UI设计技能分析390×844手机商店。我现在选商品后还要向下找英雄，想减少来回滚动。
>
> 请先提出两种局部布局，目标是选中商品后同时看清物品、价格、目标英雄和四个槽位；考虑固定商品摘要和紧凑英雄切换。保持没有背包、只能商店穿戴、空槽直接穿戴、替换需确认的规则。不要改价格或新增购买步骤。
>
> 每种方案画默认、选中商品、替换确认三个状态，说明长物品名、钱不足、取消时怎么处理。我选定后再实施，并用真实触摸流程和截图验收。

### 可以直接复制：动作反馈

> 先设计装备成功的反馈，让我能看出物品去了哪个槽、属性变了多少。反馈要短促、局部发生，不挡住下一次操作。请说明触发时机、持续时间、结束状态、减少动态模式下如何呈现；逻辑成功后播放，不让动画控制交易。先给方案，确认后实现。

## 建议的推进顺序

1. 战斗的信息层级和手机可读性；商店购买/替换/合成的选择路径；成长收益比较。
2. 招募差异表达、战前点数提醒；统一字体/按钮/间距和一套技能装备图标。
3. 结算构筑复盘、正式英雄美术和必要动作；实测后做性能档位。

第一步建议用**桌面战斗页的一个局部**做风格样板，用户选定后扩展。本文没有批准整页重做，也没有把草图或审阅冒充游戏已优化。
