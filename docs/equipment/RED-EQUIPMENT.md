# 红色成装整批设计稿（R060）

2026-10-20（北京时间）。用户在接受12件紫装后要求“继续”，本轮按上一轮红装计划一次设计19件、26条配方。范围授权见[D031](../decisions/D031-red-equipment-scope.md)。具体条目及红紫同名等级细则为本轮提案，尚未获用户接受、尚未接入游戏。

已接受的12白/21蓝/26紫不改；加上19件新提案，设计目录共78件。当前运行池仍47件，另12件紫装已接受待实施；橙装尚无正式条目。红装是普通合成终点，橙装仍只能开出、不能由红装合成。

## 本批规模与价格

物理7件、法系5件、防御4件、辅助3件。26件紫装各有一条去向，七对用途相近的紫装汇入同一红装，避免扩成26件以上的同质成品；这是首批覆盖，不禁止未来有充分理由时增加分支。25条配方为紫＋蓝，一条为紫＋白＋白；全部保留材料基础属性。每件最多一个命名被动，晨星保留纯法强比较基准。

总价3000–3600金，合成费400–1150金；同一成品不同配方的材料标价不同，补费也不同，但总价固定。效果预留400–750金，占带被动成品12.1%–22.7%；这是本批报价工作区间，不是已经确认的所有红装硬性上限。费用核对见下表与工具。

### 红紫同名如何同时装备

1. **每英雄、每effectId只启用最高rank的一整份。** 不能把紫版冷却和红版数值拼起来，也不能各跑一套计数。红装与紫装基础属性照常相加。同rank必须具有同一组效果参数，重复件不叠效果；若后续内容同rank参数冲突，应拒绝该内容定义，不能按装备槽顺序偷偷择优。
2. 本批没有战斗中换装，合成仅在商店；每场重建最高级效果并重置计数/层数/历史，独立冷却开场就绪。合成或重排槽位不在同一战斗里刷新计数、充能或法力。不额外设计战中动态降级、拆解或卖出退差价。
3. 例：风暴＋鏖战基础攻速48%＋24%=72%，穷追只给红版18%，叠满总计90%；两件风暴是96%＋18%=114%。决胜＋连击每第3次只触发45%，不变75%；两件裁决基础暴击共32%，倍率增量仍0.30；赤潮单件半血下共12%吸血，重复件基础可叠但血性只＋6%。
4. **应援跨持有者的目标端规则**：同一受益者只留一个应援盾。高rank施加覆盖低rank，按新盾量与新期限建立；同rank取较大剩余值并刷新4秒，不累加；低rank不能替换或延长尚有效的高rank盾。一次符合条件的施加尝试仍消耗施加者冷却，即使被更高rank挡住，也不转给另一个目标。高rank盾到期/耗尽后，下一次合法低rank触发才可重新施加。避免低级挂坠不断给高级180盾续时。
5. 已经成功施加的应援盾在施加者死亡后仍保留自身剩余期限；死亡持有者不再产生新触发。不同名盾可共存，沿R053先消耗较早到期临时盾、同到期按effectId/来源ID、最后无期限盾；破魔绕过且不消耗。战意护盾是持有者自己的同名一份，与应援分别记账。

### 三条被动转换路线

- 血契长刃＋迅捷双刃→赤潮：**回流转为血性Ⅱ**。保持物理续航方向，但从命中后持续回血转成低血普攻吸血；想保留回流可暂不合成，不能暗中保留两个被动。
- 铁卫战刃＋征战长剑→赤锋：**卸力转为背水Ⅱ**。保留攻击/护甲、增加生命，选择低血反击方向；这不是“减伤被动数值提升”，合成预览必须明示失去卸力。
- 静心法杖＋护身法杖→破阵：**隔魔转为应战Ⅱ**。从针对魔伤保护转为混合抗性战斗法师；固定魔抗仍在，但不保留6%额外魔伤减免。

这三条属于可选转型，而非全维度无损升级。所有路线保留的是材料**基础属性**，材料被动由成品定义替换。以后可根据实战补同机制终点，不为首次26紫全覆盖再堆三个几乎同面板红装。

## 估值条件、长短窗口和升级费用

[核算工具](red-equipment-balance.py)读取正式47件与已接受12紫材料，并读取[本批JSON](red-equipment-r060.json)，不改游戏或历史报告。运行：

```sh
python3 docs/equipment/red-equipment-balance.py
python3 docs/equipment/red-equipment-balance.py --json
```

- **计价与升级增量**：每件红装按全部基础属性＋自身效果预算收费。对每条配方分别核对：合成费＝基础属性预算增加＋效果预算变化；不先保留紫装完整被动价格再给红被动重复加钱。例连击＋决斗：材料2450，属性从2025到2550增加525，效果预算425→750增加325，所以补850，总价3300。血契转赤潮虽然更换机制，也按成品自己的效果预算计算，不凭空附送回流。
- **攻击系**：固定装备后的总AD、总暴击、成功普攻频率及AD技能收益导数，分别开关效果。三重打击与狠厉以额外DPS除以增加1AD带来的DPS，折获取价；基准含AD技能，不把“增加普攻10%”当总伤害10%。参考三组`AD/暴击/成功普攻每秒/物理AD技能每秒系数`为`160/.2/1.2/.6`、`220/.3/1.8/1.2`、`320/.5/2.5/2`；同物理减免、无限观察的局部斜率，无过量/击杀反馈。混合伤害AD技能必须改用对应减免后斜率，不能直接复用这一表。
- **攻速系**：穷追把叠层、转火、空档合并成等效满层覆盖40%/70%/90%；乘风按规律的成功普攻和独立暴击计算稳态覆盖，分别1.2/1.8/2.5次每秒、20%/30%/50%暴击、3秒持续。频率为外部输入，不声称解出了攻速反过来提高暴击触发的反馈；开场短窗更低，后期接近常驻最多24个百分点，也不按100%概率额外收费一次。
- **条件属性**：血性按低血、合格生命伤害及有效回血的联合兑现30%/55%/80%，不是只看低血时长；背水按AD收益加权低血35%/55%/80%；应战按AP收益加权触发40%/65%/90%。回春低血有效回复覆盖30%/50%/70%，均势混伤有效覆盖40%/70%/100%。未触发、满血、无相关伤害/技能时可以为0，不将示例最低格当真实保底。
- **回复与资源**：沿R053以实际能触发次数×固定值×有效兑现率折持续回复。滋养开场满血首触浪费，援手/济能参考第2秒起首个有效辅助施法。40秒中相关技能间隔14/6/4秒，分别50%/80%/90%兑现；济能中间值75%。冷却按施法事件离散取整，不按8秒冷却强行每8秒触发。施法次数是外部假设，没有假定未设计辅助能无限蓝施法。导流按40秒参与2/6/12怪、兑现50%/75%/90%，每怪只计一次，不乘队友数量；回复可用性不等于额外技能已经放出。
- **余韵有限蓝诊断**：单主动150＋1AP、50蓝、基础CD6秒、开场300蓝/5每秒回蓝、零吟唱；装备15急速，装备外AP0/80/200，分别1/3/5目标。用有理数时间推进真实扣蓝和等待，不补怪、不产生导流资源。附伤只落一个主目标，与所附技能同命中；80%共同命中率与50魔抗仅用于期望伤害，AP等价时共同因子抵消。40秒为8次技能、3次余韵；外部AP80时额外173.4原始单体伤害，等价约433.5金。群体技能AP同时增强多目标时，单次余韵的AP等价按目标数下降，不能反而把附伤乘3或5。5/10/40/180秒×3AP×3目标共36组列在JSON输出；这是独立单技能模型，不是烬璃/朔影实测。
- **防御类**：固定无治疗/控制的平均压力，防御折获得相同生存增量所需的额外生命，公式`H×[1/(1−减压比例)−1]×2金`；不再叠一次回复价。坚忍参考`H/合格命中每秒/减免后DPS`为`2500/1/300`、`3500/1.5/250`、`5000/2/250`，每击至少12；实际低于12须按原伤封顶。魔障参考H2500/3500/5000、各魔伤段**超出8%H的部分**占总承伤15%/25%/40%，不是命中次数或整段魔法占比。生命增长会放大减伤生命等价，同时提高魔障门槛，需实际伤害段复核。
- **护盾类**：战意盾用`50×成功普攻每秒/4×有效吸收率`近似平均减压，三组`H/命中频率/吸收率/压力`为`1800/1.2/40%/250`、`3000/2/80%/250`、`4000/2.5/90%/200`。只作持续压力敏感性，未模拟前三次普攻空窗、护盾刷新损耗和死亡；不能作为5秒爆发实际成绩。应援按40秒1/2/3次，吸收50%/75%/90%，只将有效吸收/秒折持续回复价；不再加算一次180生命价格，单次爆发保护另看180盾最多360生命获取价。

工具另列滋养/援手/济能5/10/40/180秒×4/6/14秒间隔共36组资源诊断。不能将36＋36个独立模型格子描述成真实游戏场次；没有测未实现红装的真实命中/过量、完整多技能托管、队友死亡、有限敌人或同预算四件套。

## 组合与经济复核

- 风暴叠满提供自身48%＋18%=66%攻速；与裂风不同名乘风可相加，但乘风不会多开一份，实际持续普攻提升还需除以已有攻速总池。与裁决配合会同时提高暴击覆盖和暴伤，不能简单相加两个单件百分比当总DPS增幅。
- 三重打击依然不吸血。赤潮的12%低血吸血只对普攻本体实际生命伤害，不能把45%附伤也拿来回血；狠厉提升合格暴击本体可以提高有效吸血，但同一收益不重复向两个被动收钱。
- 铁壁与保留的紫铁卫卸力：护甲后100合格物理普攻→92→80，坚忍只用红版12。镇魔法袍与紫静心隔魔：H=3500，其他减免后500魔伤先470，超出280的190再减25%，结果422.5；破魔只吃基础魔抗与适用通用减伤，不受这两个magic专属被动保护。
- 守望的高攻速/高血量、导流的高参与击杀，以及多个保护来源使表中强条件约1309/1350/1012金，明显高于对应500/650/600预留。坚忍/魔障也随生命与压力构成变动；这些是需要复核的协同，不宣称所有强条件都被当前报价压到同一价值。红装中的升级量有限（例如导流15→20而非30），现有紫装参数未为掩盖风险被改动。
- R049当前8种子全队击杀收入中位约8310金，且固定怪物曲线后收入下降。它是**全队整局**收入，不是每英雄可支配8310；免费宝箱/材料供给还需另计。不能据此承诺每名英雄每局能穿满4红，也不能拿本批标价直接改金币、掉落或刷新价。实现后须实测首件红装出现层数、每队成装数、补费等待、材料占槽和分配竞争。
- 当前试玩可从全队已穿戴装备取材料、无背包。每条配方实例必须唯一，裁决的两把尖刺短刃须为两个UID；不同路线只是同一成品的替代配方，不同时消耗两套。依然只扣所选路线补费，不额外收一遍材料价；出售沿实际实施规则，不新增拆解或退费。
- 下一阶段按同预算、四槽、相同英雄等级与站位，测试单件/四件套及1/3/5压力源的5/10/40/180秒；加入低血、满资源、开场暴毙、转火、混伤/真伤/破魔与辅助多人同名盾。与R049敌人、已接受的新英雄版本分开标记，不能用当前47件的测试通过证明新增红装已验证。
