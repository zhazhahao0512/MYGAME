# HB-1.0 · 统一英雄输出、承伤与成长测试方案

2026-10-19，R031。**设计方案／参数工作稿，尚未接入战斗引擎或测试页面。** 用户要求所有英雄共用1／3／5目标、不同攻防木桩、成长曲线与装备增幅标准；范围见 [D014](../decisions/D014-hero-benchmark-scope.md)。[参数清单](hero-benchmark-v1.json) 是同版本机器可读输入，[核验脚本](check-hero-benchmark.py) 只检查配置与参考算式。

目标是让每位英雄都有可比较的能力档案，而不是让坦克、辅助、刺客、射手都达到同一个DPS。遵守 [D013](../decisions/D013-hero-skill-roles.md)：核心、配合、有限补短板，并为后续质变留余地。以下具体木桩数值、压力与预算为本轮选定的首版建议，不冒充用户逐项确认。

## 1. 固定什么，分开比较什么

| 维度 | HB-1.0 建议标准 |
| --- | --- |
| 主锚点 | 英雄15级，技能按合法点法；法强只能来自装备 |
| 成长采样 | 1、2、3、5、6、10、15、16、20、25、30级；30不是等级上限 |
| 时间 | 同时报告开场5秒、10秒、40秒、180秒；都从冷启动开始，不挑伤害最高的片段 |
| 人数 | 1／3／5个敌方目标或压力源；不得把三目标总量当单体数据 |
| 公共站位 | 英雄3号位；单目标[3]，三目标[2,3,4]，五目标[1,2,3,4,5]，优先3号目标 |
| 位置补测 | 英雄分别站1／3／5号位；另报预先登记的推荐站位，不能只挑最好位置横比 |
| 资源 | 满生命、满法力、无外部预叠层；技能剩余冷却0，固有起手规则/初始充能按英雄定义保留 |
| 行动 | 使用实际技能吟唱、飞行、行动占用与20ms模拟时钟；没有这些定义时标“估算”，不能混入引擎实测榜 |
| 随机 | 固定种子0–255；接近或波动大时扩到0–1023；同条件配对比较 |
| 版本 | 标准、引擎、英雄、装备、海克斯、触发规则版本都必须记录；不跨版本直接排强弱 |

输出使用英雄真实的近战／远程命中规则，不强制都按远程；公共站位结果与推荐站位结果分别报告。按项目现有精准公式、四伤害类型、发射快照、到达扣血、唯一目标ID结算，不额外添加命中保底、属性上限或普攻特效权限。

主报告固定合法技能顺序与自动施法策略；另一条主／副路线独立命名。允许专门优化策略，但必须同等搜索预算、公布规则，再用未参与选择的种子复核，不把手动最优操作与默认自动对打。查询可用技能不消耗随机数。

## 2. 被英雄打的木桩

下表是**15级参考值**。T0–T8可做输出潜力与有限生命测试，T9必须扣真实生命才有意义。

| ID / 类型 | 生命 | 护甲 | 魔抗 | 额外特征 | 检验什么 |
| --- | ---: | ---: | ---: | --- | --- |
| T0 零抗 | 3000 | 0 | 0 | 无 | 核对原始伤害构成；不代表实战 |
| T1 均衡 | 3000 | 50 | 50 | 无 | 公共主基准 |
| T2 高血 | 6000 | 50 | 50 | 无 | 百分比伤害、长时间作战 |
| T3 高护甲 | 3000 | 150 | 30 | 无 | 物理路线受限及混伤价值 |
| T4 高魔抗 | 3000 | 30 | 150 | 无 | 魔法路线受限 |
| T5 双抗 | 3000 | 150 | 150 | 无 | 穿透／真伤及高抗压力 |
| T6 减伤 | 3000 | 50 | 50 | 20%直接减伤 | 减伤与真伤差异 |
| T7 护盾 | 3000 | 50 | 50 | 开场及每10秒盾900，持续10秒 | 打盾、破魔与爆发窗口 |
| T8 闪避 | 3000 | 50 | 50 | 闪避20 | 精准与低频攻击稳定性 |
| T9 回复 | 3000 | 50 | 50 | 生命回复60／秒 | 净压血、压过回复、减疗价值 |

T7同一来源只刷新剩余盾至900，不叠加；同刻先到期，再补新盾，再按版本固定事件序处理到达伤害。过期/替换掉的盾不是英雄造成的盾伤。T6真伤不受其减伤但仍可被闪避；T7真伤先扣盾，破魔吃魔抗/减伤却直接扣生命且不耗盾。这些关系沿用已确认规范。

每种木桩分别测1／3／5只；默认每只相同属性，群体总血量自然增加。补充三目标混合组[T2,T3,T4]与五目标混合组[T2,T3,T4,T7,T8]，按槽位升序放置，并另跑所有循环轮换布局，避免固定位置恰好克制某一英雄。每个轮换等权，不能仅用`seed % N`造成布局次数不齐。

有限目标另外可做“总生命固定3000、每只分3000/N”的小怪测试，但必须标记`fixed_total_hp`，不能与默认每只3000混成一条曲线。群体技能的目标上限、重复命中与溅射由英雄定义决定，不能把不足的箭或弹射次数擅自合并到Boss。

## 3. 四种输出模式，解决不死木桩的盲区

**O1 输出潜力**：木桩声明真实的生命上限H，分别锁定100%／50%／20%生命状态，只把通过命中、抗性、减伤后的伤害记作潜在伤害，不扣生命、不触发击杀。百分比伤害必须使用H和所选生命状态，禁止用十亿血或数学无穷当分母。护盾仍按时获得与消耗，盾后潜在生命伤害另记。只为隔离技能倍率和触发频率；斩杀不转换为虚构伤害，吸血不从潜在伤害产生有效回复。依靠实际扣血、吸血、自伤或击杀循环的英雄不能只用O1判断，必须配O2/O3。

**O2 有限目标击杀**：真实扣血、护盾、回复、吸血、斩杀与击杀触发，击杀后不补充。报告首杀时间、各目标击杀时间和全部清空时间；超时保留剩余血盾与右删失标记。技能过量伤害不记有效伤害。若两人都清空同样一批，40秒有效DPS可能相等，**清空时间才是主要差别**，不能据此判两人输出相同。

**O3 持续换靶**：有限生命目标死亡后1秒在原槽补同档木桩，使用新ID；新目标满资源，英雄的状态和法力不重置，装备同目标层数按既定规则处理。报告击杀数、每分钟击杀、有效伤害、空档损失和击杀刷新收益。1秒是基准夹具参数，不修改当前游戏6秒批次补怪规则。

**O4 攻守同时发生**：使用第4节压力源和有限生命敌人，双方正常战斗。死亡后的剩余窗口输出记0；另报存活期间DPS。观察脆皮能否打出理论伤害、控制能否提高输出、生存装能否增加整个窗口有效输出。

所有模式另外提供“强制命中／无限蓝”的独立诊断开关，默认关闭，结果带标签、不进入正常实战口径。不能用该诊断绕过闪避、法力、控制或施法时间后仍称标准成绩。

## 4. 攻击英雄的压力木桩

以15级为锚点，每个标准压力档的**预定减免前DPS为200**，不带暴击、穿透、装备特效；精准95、远程距离系数2。它是独立压力模板，不是某个正式怪物。所有伤害都按精准／闪避判定。

| ID / 类型 | 基准频率与伤害 | 用途 |
| --- | --- | --- |
| A1 常规物理普攻 | 每1秒200物理 | 护甲、普通防御、闪避 |
| A2 高频普攻 | 每0.25秒50物理 | 固定挡伤、受击触发、护盾消耗 |
| A3 重击普攻 | 每2秒400物理 | 小额高频与大额低频的差异 |
| A4 持续魔法技能 | 每1秒200魔法 | 魔抗与技能承伤 |
| A5 魔法爆发 | 每4秒800魔法 | 护盾时机、突发暴毙 |
| A6 混合 | 每1秒100物理普攻＋100魔法技能 | 综合生存、伤害来源限定防御 |
| A7 真实技能 | 每1秒200真实 | 生命、回复、护盾与闪避价值 |
| A8 破魔技能 | 每1秒200破魔 | 魔抗价值和绕盾压力 |

默认低／中／高压力为×0.5／×1／×2，即15级100／200／400预定原始DPS。低压测续航，高压测暴毙，不能以某英雄自身生命百分比生成伤害，否则堆生命会自动抬高敌人伤害，失去公平性。

每档测1／3／5个来源，槽位使用第1节相同布局，并分两种口径：

- **等总压**：所有来源总共200 DPS；三来源各200/3，五来源各40。保持各自攻击频率、分摊每次伤害，测多来源／受击次数敏感性。
- **集火加压**：每个来源200 DPS，总计200／600／1000。测实际被多人集火的生存极限。

基础脉冲按周期中点安排，N来源默认交错相位`period×(i+0.5)/N`，另测全部同相位`period/2`。这样40秒窗口内计划伤害总量可核对；控制、闪避、减免与死亡会降低实际到达伤害。基础压力源零吟唱、零飞行，瞬时脉冲，不含预备动作；**英雄自身仍用真实行动时序**。可打断长吟唱、射程规避等需要独立扩展模板，未测不能写成没有价值。

两个附加压力条件单独叠在A6上，不混入基础成绩：C1每8秒一次1秒眩晕、首次4秒、可闪避且受英雄韧性；C2持续40%回复抑制，作用于治疗／吸血／自然回复，不减护盾。它们是建议测试条件，不是在本轮给游戏新增敌人技能或确认通用减疗公式。压力源若受控制而无法行动，跳过该次计划脉冲、不在恢复后补发；控制避免的计划伤害单独记账。

## 5. 承伤的三种口径

**D0 静态抗打**：保留生命、双抗、闪避、常驻减伤等静态属性；禁用攻击、主动、自然回复及触发式护盾／治疗。用于分解基础面板价值，不用于给护盾坦克或吸血战士下最终结论。初始满血、无外部盾。

**D1 完整技能、固定压力**：英雄正常攻击／施法／回复，压力源不会被杀。为使吸血产生真实扣血依据，源单位用T1的标称血量：每个完整根行动开始前恢复到H，根行动内真实扣血且最多扣到0，整条附伤/触发链结束后再恢复；恢复不触发治疗、复活或新目标事件。记录实际扣血供吸血使用，禁用击杀／死亡收益，单位ID保持，目标叠层不重置。此模式是明确的反事实训练夹具：可测直接防御／回复／控制，但不能衡量“杀死敌人就是生存”的能力，也不能拿源单位重置后的伤害当正常击杀DPS。

**D2 完整有限战斗**：压力源拥有T1或指定防御模板的真实有限血量，死后停止攻击；基础组不补怪，扩展组按O3补充。英雄的输出、击杀、控制、转移仇恨等可减少压力，是完整生存价值。把D1与D2并列，避免只奖励纯承伤或只奖励先秒敌人。

三组都记录生存概率、死亡时间、40/180秒剩余血盾、有效治疗、实际吸收护盾、敌人成功命中率、控制避免的攻击与伤害。未在窗口死亡只能写`存活≥T秒`，不能写无限坦度或把T当真实死亡时间。报告`RMST(T)=平均min(死亡时间,T)`与生存率；不足一半死亡时中位死亡时间写`≥T`。有额外复活的英雄报告首次死亡与最终退场时间分别统计，不能抹去死亡事件。

基础承伤等效生命只在无回复／护盾／控制的静态单类型条件下使用，例如物理`H×(1+护甲/100)`；一旦涉及闪避、治疗、临时减伤与伤害混合，改用上述生存试验，不硬凑一个固定EHP。

## 6. 辅助英雄也有共同参照

使用固定四名无独特被动的陪测队友，受测英雄在3号位：1号前排H3000/护甲100/魔抗50、不攻击；2号物理射手H1800/双抗50/AD100/攻速1/精准95/远程；4号法术单位H1800/双抗50、每1秒尝试施放100魔法伤害、吟唱0.2秒、耗蓝20/初始蓝200/回蓝5；5号受保护单位H1800/双抗50、不攻击。其它特殊属性0，射手普攻及法术单位技能飞行0.2秒，所有攻击按真实命中规则。上述为15级固定陪测，不是新英雄；成长测试中要注明陪测是否固定，不能偷偷给陪测升属性。

对照组留空3号位，实验组加入受测英雄；同一组敌人／种子／策略。默认三名T1敌人[2,3,4]同时作A6等总压200，优先攻击1号，失效时按[2,4,5,3]继续；群疗补测每名存活友方等分压力。物理队友优先3号敌人，失效按槽位升序；法术队友同策略。技能自行指定合法治疗／护盾目标，不能替英雄加额外治疗权限。

报告**队友额外DPS**（只算原四名队友）、英雄自身DPS、队伍总DPS、队友存活率、有效治疗HPS、实际盾吸收／秒、控制覆盖和敌人少打出的伤害。满血过量治疗、过期护盾不计有效贡献；守护／转伤只是改变承受者时不能当作整队免伤重复加分。也跑前排、射手、法术队友分别承压的子场景，避免辅助只因固定目标偏好受益。

## 7. 成长曲线与装备增幅

每个等级点必须登记合法技能等级与顺序；15级后固定成长继续。分三条曲线：

1. **纯面板／技能成长**：裸装；16级后额外属性选择暂存不分配，隔离自然成长。这是测试控制，不取消游戏升级奖励。
2. **成长＋固定选择**：每位英雄预登记一条合法选择路线，按相同次数与获取预算获得属性；记录具体选择、实际金币估值，法强不进入升级选择。
3. **完整构筑成长**：加入相同装备预算和相同海克斯数量／品级条件，逐等级独立报告，不把装备更新和技能升级混成自然成长。

每条曲线同时输出两种敌人标尺：**固定15级木桩**看英雄绝对成长；**同级木桩**看成长能否跟上压力。首版缩放为：`H(L)=600+160L`、`R(L)=20+2L`、`P(L)=80+8L`。木桩类型用第2节倍率，如高血2H、高护甲3R/0.6R、护盾0.3H、回复0.02H/秒；闪避20和直接减伤20%不随等级涨。压力档和来源数再按第4节应用。该曲线是实验尺，不决定正式敌人、关卡经验或无限成长上限。

装备预算档为 **0／1500／3000／6000金**，沿用4槽、最多1件橙装、同名被动唯一与基础属性叠加。每位英雄可登记主输出、第二路线、偏生存构筑，在同一预算和同一已发布装备池内比较，不要求法师与射手穿同一套装备。必须记录实际花费与未花金币；花费差距超过预算5%标记“预算未齐”，不能用每千金收益线性补齐后冒充严格等预算。

**技能升级收益**另设固定等级对照：只改变被测技能等级，其它技能、装备和策略固定，未使用点数暂存。每个配置必须能由合法加点历史达到；普通技能从1到4增加3点，大招从1到3增加2点，分别报告总收益与每点收益。主升路线比较则使用同等级、同已花技能点的完整合法点法。除DPS外，同时列清场时间、蓝耗、生存和辅助变化；不同技能的边际收益不能直接相加为整套收益。

报告`DPS增幅=(装备后DPS/裸装DPS−1)`、`每千金收益=1000×(装备后DPS−裸装DPS)/实际花费`，生存也单独比较生存率/RMST增幅。分母0写不适用，不输出无穷。逐件增量固定其余装备再加一件；完整套装结果用于发现协同，不能把单件收益简单相加。全池搜索与手工候选分开，禁止称未穷举结果“最强出装”。

## 8. 海克斯与长短板检查

主表无海克斯；后续增加单个强化和同品级／同数量组合，用真实已设计规则。尚无正式强化时可用X1额外攻速+50个百分点、X2急速+30、X3获准攻击特效附伤×1.5作**实验扰动**，不消耗金币、不冒充正式海克斯；X3不能自动增加护盾量、控制、计数次数或开放技能携带资格，适用效果必须逐个登记。

做无强化／A／B／A+B配对，记录`交互量=M(A+B)−M(A)−M(B)+M(无强化)`；DPS与生存分别计算。正交互不自动等于失衡，但若同时显著提高单体、群体和生存且没有资源／窗口／目标数代价，就应按D013优先复审。额外攻击、溅射携带、击杀刷新必须有专属触发说明再测；未支持标`not_supported`，不能当收益0。

保留固定成长不封顶，不凭本标准新增全局攻速或减伤上限。技术触发队列抑制、负冷却、同名被动重复、无限连锁须作为异常单独显示；测试被技术保护截断时结果无效，不能把截断后的DPS当作正常平衡。

## 9. 统一结果与记账规则

- 固定窗口DPS一律除以预定T，英雄死后记0；可另列存活期间DPS，明确分母。单目标、主目标、三／五目标合计和每目标均值分列。
- **有效HP-DPS**只计实际生命损失；**盾伤DPS**单列；二者之和称有效总伤DPS。O1只报潜在DPS，不假装造成了有效生命损失。回血后再次打掉的生命算新的实际伤害，同时列净生命变化和TTK，不能把目标回血误解为低输出。
- 有限目标中过量部分单列；斩杀只记真正损失的剩余生命。反伤、召唤物、持续伤害、装备、技能、被动按来源归属，不重复记给母体与召唤物。穿盾伤害不凭空记盾伤。
- 压力账分预定原始量、控制阻止、实际发出、未命中、命中后减免、护盾吸收、生命损失、过量；治疗和资源支出另列。增伤可使“减免量”为负，不硬裁到0。生命核对为初始＋有效治疗−实际伤害−自耗−上限回落裁剪＝结束生命，复活单独分段。
- 给出均值、标准差/P10/P50/P90、配对差值与95%置信区间；生存率和删失数据用对应统计，不以“活着的人平均伤害”代替整组结果。样本误差与模型假设误差分别说明。
- 结果必须含标准/内容/引擎版本、种子、等级/点法、构筑/预算、额外成长/海克斯、木桩类型、人数/站位、资源与行动模式、窗口、触发规则版本及未支持项，字段见JSON。无关字段显式为null，不暗中套默认。随机流按单位/攻击/技能/刷新分开，固定算法与种子派生版本。

每名英雄最终展示一张能力档案：5/10秒爆发、40秒持续、180秒续航、1/3/5目标、不同防御适应性、不同压力的生存、辅助贡献、等级曲线、装备与质变放大率。先看同主要方向与近似资源条件，再看跨类取舍；不输出一个把所有维度强行加总的“总战力”。偏弱或偏强只是复审信号，最终结合机制、关卡与实战验证。

## 10. 执行顺序与现有结果迁移

首批核心测试先做15级、0/3000金：T1的1/3/5目标，T3/T4单目标，A1/A2/A4/A6/A7/A8单来源等总压；输出潜力、有限击杀和完整承伤分别报表。然后加T2/T5–T9、1/3/5集火、推荐站位、辅助与成长；最后做海克斯组合。不要从第一天就把全部维度做完整笛卡尔积，更不能把未跑的格子填0。

落地建议分四步：先确定并冻结HB版本参数；再用实际战斗引擎补齐精准、四伤害、行动与触发契约；随后接入英雄适配、场景/结果导出与回归；最后做可视化曲线和批量对照。缺失或有争议的能力标不支持／候选分支，Q001/Q009未定稿时不能默默把某个猜测定成所有英雄规则。
