## 1. 定位与差异

暂名烬璃，远程法师，细分为印记引爆/范围爆发，建议3–4号位，可按压力换位。岚牙以普攻频率驱动附伤，烬璃依赖技能命中与印记组合，一轮高伤后有冷却/蓝量空档。

1是主要范围伤害，2帮助叠印引爆，3只补短时生存，4提供一轮大范围爆发。可走高法强、急速连招、蓝量续航或法强生存混合；不要求同职业固定一条路线。普攻为物理，无AP加成，基础AP和成长AP为0；装备法强提高技能单次强度和护盾，不直接增幅普攻。原生不提供硬控、位移、治疗、穿透、重置冷却或免费连发，给刺客与辅助保留职责空间。

## 3. 被动与技能

L为实际英雄等级，AP为装备法强。以下伤害均为减免前魔法伤害，斜杠依次为技能等级；普通技能4级，大招3级。

### 被动 · 余烬印记

1、2、4技能主伤段命中目标后施加余烬，持续8秒；一般一次施加1层，**2技能一次总共施加2层**。同一目标达到3层时清空印记，额外造成：

**24＋6×L＋40%AP魔法伤害。**

- 每个敌人独立计数，新增层刷新该来源全部层的8秒期限；达到3层每次主技能命中最多引爆一次，超出层数不保留。被动、装备附伤、普攻和队友技能均不叠印，3仅护盾也不叠印。
- 单个主动对同目标只判一次叠印，即使未来表现拆成多段也不多给；未来海克斯若改变此规则须单独算预算。不存在每层持续灼烧伤害，只有叠满后的引爆。
- 引爆与触发它的主段共用命中，主段闪避则不叠印；引爆数值用该主段发射时L/AP快照，结算目标盾/生命用落点状态。不另抽一次命中、不暴击、无普攻/全能吸血、不再次触发攻击特效/技能施放或叠印。
- 主伤害后目标仍存活才叠印/引爆；死亡后印记消失，不能传给同槽新怪，过量不扩散。期限到点先过期再处理新落点。等级不封顶，L部分继续增长，不属于法强自然成长。

### 1 · 焰核迸裂：核心输出

向当前策略主目标及邻近敌人发射焰核，最多3个不同目标，各造成：

**115 / 170 / 225 / 280＋95%AP魔法伤害**，命中各施加1层余烬。

冷却9 / 8 / 7 / 6秒；耗蓝38 / 44 / 50 / 56。施法0.25秒、弹道0.25秒为逻辑建议，不涉及动画制作。目标少于3人不把余下伤害集中到同一个目标；主目标后按槽位距离选邻近者，并列槽位号小者优先。

### 2 · 引火烙印：帮助引爆

攻击最多3个不同目标，每个造成：

**45 / 70 / 95 / 120＋40%AP魔法伤害**，命中一次总共施加2层余烬。

冷却14 / 13 / 12 / 11秒；耗蓝32 / 36 / 40 / 44。施法0.2秒、弹道0.2秒。没有额外减魔抗或易伤，避免叠印技能同时再给完整伤害乘区。

适合2→1快速引爆，也允许1先命中后用2引爆；不是固定连招。普通自动沿选敌策略，托管可在现有合法候选中比较可引爆目标和威胁，明确手动/固定目标指令优先；不因某目标有印记就忽略关键威胁。

### 3 · 烬衣：有限补生存

瞬发获得持续3秒的自身护盾：

**80 / 105 / 130 / 155＋55%AP。**

冷却18 / 17 / 16 / 15秒；耗蓝32 / 36 / 40 / 44。只保护自身，不额外治疗、减伤、免控或回蓝；同技能刷新替换，不叠多份，不叠余烬。开盾不重置普攻；现有施法占用/控制限制仍适用，不能把“瞬发”当成可以强行打断自己吟唱救命的许可。

### 4 · 天火坠落：范围爆发

一次轰击最多5个不同敌人，每个造成：

**220 / 320 / 420＋110%AP魔法伤害**，命中施加1层余烬，目标原有2层时正常触发被动。

冷却60 / 52 / 44秒；耗蓝80 / 95 / 110。施法0.6秒、弹道0.35秒。伤害目标在释放时确定，已经死亡或未在该次目标列表的后来入场者不补吃；被打断按现有扣蓝/CD规则，不返资源。

大招不把所有目标自动叠满，不重复引爆空印记，不刷新1/2，不按目标数回蓝，不将少目标的剩余份数折给单体。双抗/距离命中照常，保留高魔抗、精准不足、打断和被切入的弱点。

## 4. 触发、加点与资源

所有主动伤害沿现行远程命中规则逐目标判定，默认不暴击/不携带普攻特效/不触发普攻吸血；1/2/4可沿现行规则获得全能吸血，基数只含实际生命损失，被动引爆禁吸血，3不造成伤害。余韵对一次主动的主目标首段只绑定一次；导流按实际伤害参与、每怪一次，印记本身没有独立参与资格。被动伤害可正常建立伤害参与，不生成第二次施法事件。群体全能吸血与导流续航需纳入后续极端构筑测试，不能当免费收益。

推荐技能顺序（1–15级）：**1、2、1、3、4、1、1、2、2、4、2、3、3、3、4**。遵守2级不同技能、6级前普通最多3级、大招5/10/15；可主1副3保生存或主1副2补组合伤害，不强制定点。

托管建议：3在确有承伤风险时保命；2/1比较能否引爆及实际目标数，4比较群体/关键目标收益和剩余战况。至少留出计划中的后续1或救急3所需法力，不能为了先打2把1的蓝耗光。自动可以按设定顺序就绪即用，点击可以择时；这些是法师候选逻辑，四名一起评审后才接引擎。八秒印记有失效风险，不承诺每个已放2都一定能接到1。

## 5. 首轮算式与测试边界

15级、技能全满、同一新目标、无装备触发；指定2→1→4，三个主动全命中且目标始终存活：

| 项目 | 裸装AP0 | 辉光法杖AP80 |
| --- | ---: | ---: |
| 1单目标原始伤害 | 280 | 356 |
| 2单目标原始伤害 | 120 | 152 |
| 被动一次引爆 | 114 | 146 |
| 4单目标原始伤害 | 420 | 508 |
| 本轮单目标总原始伤害 | 934 | 1162 |
| 同上，50魔抗且无其它减免 | 622.67 | 774.67 |
| 3护盾 | 155 | 199 |

此顺序中2先给2层，1引爆清空，4最后只留下1层，不额外白送第二次引爆。这是一轮技能总伤害，不是DPS，未计命中概率/死亡过量/普攻/距离/装备触发。80AP使该组合原始伤害提高24.41%，不等于40秒DPS提升同样比例；更多法力/急速是否划算取决于实际多放了几次。

40秒零急速理想窗口：1最多7次、2最多4次、3最多3次、4最多1次，资源需求810蓝；即使不放3也需678蓝。15级自然最大供给450.6＋5.54×40=672.2蓝，且满蓝溢出/动作占用只会降低实际可用量或释放次数。高急速会增加资源压力，不提供免费的1/2重置。3须省着用，不把生存选项当每轮必开。

相同15级/AP0只换一个技能等级的理想比较：1一级到四级，单目标115→280、CD9→6，原始伤害/秒12.78→46.67；2单目标45→120、CD14→11，3.21→10.91，叠印仍固定2层；3盾80→155、CD18→15；4伤害220→420、CD60→44，40秒零急速通常都只释放一次。上述值不含被动引爆、命中和蓝耗，不能把各技能吞吐相加冒充实际DPS。

四名方案完成后再做HB真实Battle：1/3/5靶、10/40/长期窗口、同预算高AP/急速/法力/混合生存，记录直接/被动伤害、有效引爆次数、过期/因死亡丢失印记、缺蓝/断连、盾有效量/过期量、生存与装备触发。对照岚牙持续输出、砺山承伤，目标是范围爆发有优势且单体持续输出/承伤保留缺口；精确DPS阈值需在相同站位/装备/怪物版本下验证，不能用不同条件的旧分数硬比较。

本轮只有预算、加点、触发和资源算式核验；未实现引爆逻辑，未跑真实法师木桩或游戏回归。动画后置。
