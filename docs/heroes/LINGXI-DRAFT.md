# 泠汐 · 续航保护辅助建议 V0.1

2026-10-20（北京时间），R063。**助手提案，待用户评审；未修改英雄源码、未替换原型、未进行真实辅助木桩测试。** 朔影首版接受见[D034](../decisions/D034-shuoying-first-draft-accepted.md)。本稿补齐[D026](../decisions/D026-first-roster-design.md)要求的四名新增英雄方案；待本稿评审后接续统一实施，动画仍后置。

## 1. 定位与路线

暂名泠汐，主类辅助，细分为单体续航/短时保护/有限群疗；普攻远程物理，3为单体魔法。建议4–5号位，公共HB仍测3号。1负责核心治疗；2降低短时承伤，帮助治疗兑现；3以小额伤害和短控制补自保；4应对多人同时掉血。无全队常驻增伤/减伤、复活、无敌、驱散或回蓝技能。

可走法强治疗、急速法力续航、生命双抗生存三条路线，也可混搭；构筑不锁死。法强提升治疗和3伤害，急速仍受蓝量制约，生存装提高辅助存活时间但牺牲治疗强度。自身清怪弱，不能用一套辅助装替代主输出；纯输出路线可尝试但不是本稿承诺的等强主路线。

## 3. 被动与四技能

AP指装备法强。治疗数值为未计治疗增强、减疗与过量的原始量；友方治疗/保护不掷命中。存活己方英雄均可成为目标，包括自身；不复活、不治疗敌人。目标按唯一ID锁定，死亡后不转给同槽新单位。

### 被动 · 扶危

自身1/4技能每段治疗结算前，若受益者当前生命严格低于40%，该段治疗提高12%。随后应用正常治疗增强/承受治疗修正，最后封顶至缺失生命。

- 每段独立读当前血线，恰好40%不加成；持续治疗把目标抬到40%以上后，后续段恢复普通数值。
- 不增加最大生命、护盾、自然回复、吸血或装备附带治疗；不产生额外治疗事件、独立触发或层数。不是“血越低倍率越高”，不配合无限叠层。

### 1 · 回澜（核心续航）

选一名友方，立即恢复 **110/160/210/260＋0.65AP** 生命；随后3秒内，每秒恢复 **20/26/32/38＋0.08AP**，共3跳。

- CD **10/9/8/7秒**，法力 **40/46/52/58**；吟唱0.2秒、无飞行，成功施放时结算首段；后续为主动技能持续治疗，不是自然回复。
- 治疗AP与施放者治疗增强在成功释放时快照；被动低血条件、受益者减疗和缺失生命在每段落点计算。3跳在释放后1/2/3秒；不因外观拆段改变跳数。
- 同一来源对同目标重放替换未跳完的回澜，重排未来3跳，不把余量即时补发；该刷新可能损失治疗。不同来源独立，1与4也独立。
- 默认优先生命比例最低的存活友方；同分先缺失生命绝对值、再槽位/ID。托管还比较实际可治疗量和压力，避免覆盖仍足够的治疗。

### 2 · 安澜（帮助核心治疗兑现）

选一名友方，获得 **10%/13%/16%/19%直接伤害减免**，持续4秒。

- CD **16/15/14/13秒**，法力 **32/36/40/44**；瞬发，不中断自己已开始的技能。单次只保护一人，不捆绑治疗/护盾/攻速。
- 适用物理、魔法和破魔，真实伤害绕过；与其它通用比例减伤乘算，不相加变成免伤。例：原有20%减伤再获19%，总减伤为35.2%。同名安澜不叠加，保留较强比例、刷新4秒。
- 沿发射快照契约：保护只影响增益生效后新生成的伤害快照，不回改已发射弹道。技能到期不改在途快照。减免在入盾前生效，不能重复计作治疗或盾吸收。
- 默认选近期受压最大且有后续威胁的一名友方；无人受压不在托管模式空放。生效时不抬血、不救已死亡单位。

### 3 · 缚流（有限补短板）

对一名敌人造成 **60/90/120/150＋0.40AP魔法伤害**，命中后眩晕 **0.6/0.7/0.8/0.9秒**。

- CD **18/17/16/15秒**，法力 **34/38/42/46**；吟唱0.2秒，飞行0.25秒。
- 按远程精准/距离判命中，闪避则伤害和眩晕都失败；控制受韧性影响，不移除已发射攻击，不能以演出取消在途伤害。普通眩晕可阻止未来行动/打断可中断吟唱，非群控。
- 不触发普攻攻击特效/暴击/普通吸血；实际生命伤害可用全能吸血，可按现行规则参与导流，余韵只绑定主段一次。
- 托管优先能及时落点的自保/保护与可打断威胁；平稳期仅有足够蓝量才作补伤。敌方目标指令沿现行规则，不为治疗新增一套操作界面。

### 4 · 百川归潮（多人承压时的大招）

选生命比例最低的 **最多3名不同友方**，立即各恢复 **90/130/170＋0.30AP**；随后5秒，每秒各恢复 **30/40/50＋0.10AP**，共5跳。

- CD **64/56/48秒**，法力 **85/100/115**；吟唱0.35秒、无飞行。成功释放时选择目标并锁定，后续不是引导，泠汐可继续普攻/施法；施放者之后死亡不取消已施加治疗，跨战清空。
- 可含自身；同分按缺失生命绝对值、槽位/ID。少于3人不把多余份额集中给一人；目标死亡后不转移、不复活。1的后续治疗同样遵循已施加效果保留、跨战清空。
- AP/治疗增强与每跳被动/减疗/封顶时点沿1；同一来源同名效果重放替换，不堆积。没有额外护盾、瞬间满血、冷却重置或免控。

## 4. 施法、加点和资源

继续逐技能托管/自动/点击三模式，默认托管；普通自动只要合法且付得起就释放，可能满血空放/浪费减伤；点击沿现有1.5秒短指令与合法目标选择，不新增点选友军UI。友方技能不会把当前敌方目标指令当作治疗目标。

托管建议：紧急单人低血优先1与可兑现的2；至少两名队友有足够生命缺口且持续承压时考虑4，单人危险也允许按有效收益选4，不硬锁为必须两人。3可救急打断，但不能假定其必命中。使用公共留蓝机制：平时保留近期可用且有实际目标的核心治疗，团伤存在时可为4留蓝，救急可打破储备；不预测未知刷怪或偷读已抽出的命中。

推荐1–15级顺序：**1、2、1、3、4、1、1、2、2、4、2、3、3、3、4**。普通4/4/4，大招3；二级不同技能，6级前普通不超过3，大招5/10/15。副点2是默认保护路线，受压形态适合短控制时可副3，按相同规则测试。

15级裸装满蓝417、回蓝5.55/秒，40秒自然可供 **639蓝**（忽略满蓝溢出，因此是供给上界）。忽略行动占用、各技能均从t=0满转且窗口取[0,40)，可放1/2/3/4分别6/4/3/1次，耗蓝 **777**；禁放3则639。实际施法延迟、无有效目标、满蓝溢出和保护时机均改变次数，不能把恰好639理解为实战永不断蓝。不能靠纯治疗获得导流击杀回蓝。

## 6. 装备联动与后续验证

沿已接受但尚未运行的[D029紫装](../decisions/D029-purple-batch-accepted.md)：1/4对其他友军的首个有效治疗批次可各按援手/济能条件触发一次；群体3人、多跳及被动12%不复制触发，冷却中首批次检查过的施法不留到后续跳数补触发。持续治疗属于主动技能段，区别于装备规范排除的自然/属性持续回复。自疗不触发这两项；2纯减伤、3伤害也不触发它们。济能20蓝给受帮助且缺蓝的其他队友，不给泠汐自己；不构成自身无限蓝循环。援手35治疗不享受扶危、不递归。应援独立按装备规则保护其他友军，不能救已致死伤害。

运行池仍47件、新12紫装未接入；其它窗口红装进行中，本稿不固定尚未接受的红装数值。后续先按实际可用池测试，新增装备联测单独标记设计版本。治疗/减伤均不新增导流参与；3可触发余韵、伤害参与导流，遵守原冷却和唯一目标规则。

实施后沿[HB](HERO-BENCHMARK.md)固定四名陪测队友，比较空3号位与加入辅助，同种子/预算/站位：分别测单前排、射手、法师承压和群体分摊压力，1/3/5敌人，5/10/40/180秒、1–30级采样、有限蓝量、治疗抑制C2及A7真伤。主报有效HPS、过量比例、队友存活率、队友额外DPS、本人DPS、控制避免伤害、实际减免量和缺蓝时长。

必须补验：低血跨阈值逐跳、满血不触发装备、首批次冷却不留后跳补触发、少人不集中、同名刷新、目标/来源死亡、在途快照与减伤、暂停、极高急速覆盖与有限蓝量、与砺山盾/岚牙高频/烬璃/朔影组合。不用本稿算式替代真实Battle或宣称海克斯组合已平衡。
