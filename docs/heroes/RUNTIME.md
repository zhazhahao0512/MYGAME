## 已接入模块与操作

- `src/heroes/foundation.js`：八项独立面板与成长。岚牙采用原设计值；其余七名示例英雄的面板是首版兼容工作值，技能仍是演示，不声称已经完成七个正式英雄的平衡。法强/暴击基础与成长为零，法强仅装备提供。
- `src/heroes/progression.js`：每位英雄独立技能点，1级1点、15级共15点；普通4级、大招3级；2级不同技能、普通6级前最多3级、大招5/10/15。关外自主分配或推荐补点，不重置已选。16级起固定成长外三选一，选项由持久种子/英雄/等级决定；无免费重抽，无AP/暴击选项。
- `src/heroes/lanya.js`：技能各级参数、施放时状态、普攻发射附伤快照、主命中减2技能CD、专属托管估值。3技能先给精准/闪避再发箭；不触发普攻特效、不吸血；4仅接管已学1/2，不发额外施法事件、不重置原CD。
- `src/heroes/accuracy.js`：精准＋招式修正−闪避−双方槽位之和×每格衰减；近战5/远程2，无额外命中保底。旧装备focus加值映射accuracy、move加值映射evasion，只转换加值，绝不把基础move100变成闪避100；存档标记heroContentVersion，转换删除旧字段，重复读档不再转换。独立闪避上限仍按Q001记录，不在这里声称争议已解决。
- `src/heroes/growth-ui.js` / `growth.css`：战前/战后成长窗口，技能加点、后期选属性、基础与成长/金币参考。延续现有游戏配色与字体，不改背景或制作英雄动画。

### 与正式装备的兼容

装备使用 `attackSpeed` 百分比 modifier 时，英雄成长和技能2须加入同一个普通百分比池，最后才乘岚牙1.10。`heroBaseStats`保持基础频率不变，用 `bonusAttackSpeed` 表示英雄成长/技能池；当前实现把该池和装备percent相加，不先把成长乘入base后再乘装备。被动总攻速乘区不应放进普通额外攻速池。

普攻附伤应在发射时捕获数值，与主攻击共用一次命中；结算后只执行一次装备普攻命中逻辑。岚牙附伤不再次触发三重打击、穷追等计数，但实际生命/护盾伤害正常计入导流参与击杀。真伤绕双抗/直接减伤但由盾吸收。大招末尾发出的箭保留快照，不能在命中时重读当前状态。

本模块的 `lanyaMainHit` 读取发射时保存的2技能等级，冷却截止时刻保留小数格，0.15/0.25秒不逐次向上取整；实际执行仍在下一20ms步。逻辑与浏览器验证见下文；旧Python模型结果保持历史版本。


## 试玩入口与保存

正常远征随机招募岚牙。战前每名英雄下方、战后英雄面板有“成长”按钮：可逐技能升级，也可“按推荐补点”；允许保留点数。16级后的待选属性置顶，三项来自已保存种子，关闭重开不会变化。战斗只施法、不分配成长；技能角标显示当前等级，0级不可释放。

队伍每20次击杀升级，固定成长始终继续；1–15级各英雄独立技能点，16级起每级额外选择。此经验速度仅是本轮试玩值。存档保持装备version2迁移，新增heroContentVersion与每英雄progression；缺字段的旧档按推荐补齐技能，新招募保留待分配点数。读档仍重开当前关；不保存战斗中的增益/剩余蓝量。

## R048 实际战斗首轮结果

版本：随R048最终整合提交（基线5ff1bce，保留装备a3453b9）；以下数据来自实际JavaScript Battle，不是R033 Python模型。204组×16固定种子，共3,264场；本轮构建、113项测试、英雄/装备/战斗浏览器检查均通过。40秒输出窗计生命和护盾实际伤害，不含窗口之后才到达的弹道；英雄在3号位，法力有限，按推荐加点，20级额外属性未选。各木桩定义见[HB配置](hero-benchmark-v1.json)。

| 木桩数量 | 托管释放 | 自动释放 |
| --- | ---: | ---: |
| 1 | 220.52 | 222.24 |
| 3 | 257.69 | 250.56 |
| 5 | 259.47 | 253.17 |

单靶托管略低于自动，多靶略高；当前策略没有“所有情况都更高DPS”的保证。单靶40秒末托管剩蓝38.70、自动14.70；收益也包含资源余量，仍需有限击杀与下一轮实战校准。
