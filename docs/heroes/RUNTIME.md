- `src/heroes/foundation.js`：八项独立面板与成长。岚牙采用原设计值；其余七名示例英雄的面板是首版兼容工作值，技能仍是演示，不声称已经完成七个正式英雄的平衡。法强/暴击基础与成长为零，法强仅装备提供。

### 对装备窗口的兼容说明

装备使用 `attackSpeed` 百分比 modifier 时，英雄成长和技能2须加入同一个普通百分比池，最后才乘岚牙1.10。`heroBaseStats`保持基础频率不变，用 `bonusAttackSpeed` 表示英雄成长/技能池；整合时把该池和装备percent相加，不先把成长乘入base后再乘装备。被动总攻速乘区不应放进普通额外攻速池。

普攻附伤应在发射时捕获数值，与主攻击共用一次命中；结算后只执行一次装备普攻命中逻辑。岚牙附伤不再次触发三重打击、穷追等计数，但实际生命/护盾伤害正常计入导流参与击杀。真伤绕双抗/直接减伤但由盾吸收。大招末尾发出的箭保留快照，不能在命中时重读当前状态。

本模块的 `lanyaMainHit` 读取发射时保存的2技能等级，按模拟格量化减秒；0.25秒在20ms固定步按13格/0.26秒执行，此误差需要在最终实现统一成剩余时刻小数或明确量化。实际引擎/浏览器/HB结果待接入后补充，旧Python模型结果保持历史版本。
