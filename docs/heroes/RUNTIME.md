# 五名正式英雄运行规范 · R066

当前运行名单为 **岚牙、砺山、烬璃、朔影、泠汐**；用户接受辅助并明确要求完全替换测试英雄，见[D037](../decisions/D037-five-hero-roster-runtime.md)。旧七名不再进入新开局、招募或界面预览。首版数值可调整，完整平衡与动画美术后续进行。下方R048内容为历史接入记录，不再代表运行名单。

## 内容与操作

- 八项基础与成长以`src/heroes/foundation.js`为运行值，对应[LANYA](LANYA.md)、[砺山](LISHAN-DRAFT.md)、[烬璃](JINLI-DRAFT.md)、[朔影](SHUOYING-DRAFT.md)、[泠汐](LINGXI-DRAFT.md)。初始/成长法强和暴击均0，普通攻速成长相加，岚牙再乘总攻速1.10；固定成长继续。
- `roster.js`提供四名新增英雄各级技能与说明；`mechanics.js`处理实际坚毅、标记/引爆、嘲讽、条件精准/血线、分段治疗和保护；`lanya.js`保持原攻击特效方案。移除运行用通用演示技能和磐石示例被动。
- 普通技能最多4级，大招3级；二级须学不同技能，六级前普通不超过3级；大招5/10/15。1–15每级各英雄各得1点。16级后固定成长外另选属性，不添加法强/暴击选择。
- 成长窗口显示当前数值、升级后数值、蓝耗/CD及禁用原因。手动加点或按推荐补点；后者仅使用剩余技能点，保留已点方向。开战存在未用技能点时，提供推荐补齐、保留点数出战、返回手动分配。
- 推荐顺序（1–15级）：岚牙`1 2 1 1 4 1 3 2 2 4 2 3 3 3 4`；另外四名`1 2 1 3 4 1 1 2 2 4 2 3 3 3 4`。不同合法路线可自行选择，不强制按模板。
- 默认逐技能托管；保留自动/点击与圆钮。托管使用当前技能等级、命中期望、血蓝与可见压力：坦克有压力才开盾，法师考虑2→1叠印，刺客有可支付的1/4接续才标记，辅助按有效治疗和危急程度留蓝。不是全知最优连招搜索。

## 结算与装备边界

- 砺山实际敌方血盾损失存18%坚毅，上限8%HP；1消耗、4提高回收，致死不救活。2命中嘲讽只改变随后单体选敌，不取消在途伤害/已开始吟唱；来源死亡后无强制目标。
- 英雄临时盾接入R064的`timedShields`，与装备盾统一按到期先后消耗、独立到期；同来源技能盾替换。纯破魔绕盾，真实仍吃盾。暂未提供海克斯改变盾机制。
- 烬璃每目标/来源8秒标记，1/4加1、2加2，三层清空，无溢出续存；同一主段命中最多一次引爆。引爆使用发射AP/等级/减免快照，不暴击、吸血、叠印或递归普攻特效。
- 朔影1/4发射时读取目标缺血和严格40%阈值；寻隙只对一个实例的1/4加精准，普通攻击与其它目标无加成。没有处决/击杀重置。
- 泠汐1/4在释放时快照AP/施放者治疗增强，每段治疗读取当时血线与缺口；持续治疗不是引导，来源死亡仍保留既有治疗、目标死亡清除。4在释放时选择最多三人，少人不集中。2的减伤与其它减伤乘算，只影响随后生成的伤害快照，真实绕过。
- 新78件装备已合入。英雄盾使用相同有限盾账本，泠汐群疗和持续治疗共享每次施法的`action`，首个有效批次向`supportSpellBatch`报一次；1次大招不会按3人×5跳复制援手/济能。自疗、满血过量、纯减伤/标记不形成辅助装备受益者；首有效批次处于装备冷却中也不留后跳补触发。

## 已接入模块与操作

- `src/heroes/foundation.js`：八项独立面板与成长。岚牙采用原设计值；其余七名示例英雄的面板是首版兼容工作值，技能仍是演示，不声称已经完成七个正式英雄的平衡。法强/暴击基础与成长为零，法强仅装备提供。
- `src/heroes/progression.js`：每位英雄独立技能点，1级1点、15级共15点；普通4级、大招3级；2级不同技能、普通6级前最多3级、大招5/10/15。关外自主分配或推荐补点，不重置已选。16级起固定成长外三选一，选项由持久种子/英雄/等级决定；无免费重抽，无AP/暴击选项。
- `src/heroes/lanya.js`：技能各级参数、施放时状态、普攻发射附伤快照、主命中减2技能CD、专属托管估值。3技能先给精准/闪避再发箭；不触发普攻特效、不吸血；4仅接管已学1/2，不发额外施法事件、不重置原CD。
- `src/heroes/accuracy.js`：精准＋招式修正−闪避−双方槽位之和×每格衰减；近战5/远程2，无额外命中保底。旧装备focus加值映射accuracy、move加值映射evasion，只转换加值，绝不把基础move100变成闪避100；存档标记heroContentVersion，转换删除旧字段，重复读档不再转换。独立闪避上限仍按Q001记录，不在这里声称争议已解决。
- `src/heroes/growth-ui.js` / `growth.css`：战前/战后成长窗口，技能加点、后期选属性、基础与成长/金币参考。延续现有游戏配色与字体，不改背景或制作英雄动画。

### 与正式装备的兼容

装备使用 `attackSpeed` 百分比 modifier 时，英雄成长和技能2须加入同一个普通百分比池，最后才乘岚牙1.10。`heroBaseStats`保持基础频率不变，用 `bonusAttackSpeed` 表示英雄成长/技能池；当前实现把该池和装备percent相加，不先把成长乘入base后再乘装备。被动总攻速乘区不应放进普通额外攻速池。

普攻附伤应在发射时捕获数值，与主攻击共用一次命中；结算后只执行一次装备普攻命中逻辑。岚牙附伤不再次触发三重打击、穷追等计数，但实际生命/护盾伤害正常计入导流参与击杀。真伤绕双抗/直接减伤但由盾吸收。大招末尾发出的箭保留快照，不能在命中时重读当前状态。

本模块的 `lanyaMainHit` 读取发射时保存的2技能等级，冷却截止时刻保留小数格，0.15/0.25秒不逐次向上取整；实际执行仍在下一20ms步。逻辑与浏览器验证见下文；旧Python模型结果保持历史版本。


## 试玩入口与保存

正常远征随机招募岚牙。战前每名英雄下方、战后英雄面板有“成长”按钮：可逐技能升级，也可“按推荐补点”；允许保留点数。16级后的待选属性置顶，三项来自已保存种子，关闭重开不会变化。战斗只施法、不分配成长；技能角标显示当前等级，0级不可释放。

队伍当前每12次击杀升级（R048为20、R049为16；R062配合进一步提高耐久调整，[当前证据](../ENCOUNTER-PACING.md)），固定成长始终继续；1–15级各英雄独立技能点，16级起每级额外选择。此经验速度仍是试玩值；旧档等级不倒退，后续结算可能补级。存档保持装备version2迁移，新增heroContentVersion与每英雄progression；缺字段的旧档按推荐补齐技能，新招募保留待分配点数。读档仍重开当前关；不保存战斗中的增益/剩余蓝量。

## R048 实际战斗首轮结果

版本：随R048最终整合提交（基线5ff1bce，保留装备a3453b9）；以下数据来自实际JavaScript Battle，不是R033 Python模型。204组×16固定种子，共3,264场；本轮构建、113项测试、英雄/装备/战斗浏览器检查均通过。40秒输出窗计生命和护盾实际伤害，不含窗口之后才到达的弹道；英雄在3号位，法力有限，按推荐加点，20级额外属性未选。各木桩定义见[HB配置](hero-benchmark-v1.json)。
