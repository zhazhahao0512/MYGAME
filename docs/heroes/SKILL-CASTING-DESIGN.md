# 技能施法与法力管理 V0.1 · 方案草案

2026-10-19（北京时间），R037。用户要求思考蓝量限制下的施法安排及是否加入手动；本轮为可审阅方案，未获实施指令，不改游戏、英雄或装备数值。接续 [岚牙测试](LANYA-BENCHMARK.md)、[英雄定义](LANYA.md)、[当前战斗契约](../COMBAT.md) 与 [已实现说明/暂停/手动大招](../UI-INTERACTION-DESIGN.md)。下列模式、阈值和队列都是建议，不是已确认决定。

## 1. 结论与依据

建议采用“默认自动 + 每技能可切手动 + 少量战术接管”，让自动模式足以正常游玩，手动用于选爆发、保命、清怪时机。五人队伍有20个主动技能，不以频繁点击所有技能作为正常强度前提；手动不获得额外倍率、折扣或跳过施法时间。

原型已经实现大招自动/手动及独立释放按钮，不能重复描述为待新增。本方案扩展到普通技能和用蓝策略，新英雄的1–4标签及正式机制仍未迁移。

R033的15级裸装独立模型：默认优先级下40秒224.7 DPS、180秒161.0，大招180秒仅1次；全程按下一次大招冷却预留法力后，40秒211.4、180秒194.9，大招5次。原因是“大招排第一”只解决同时可放时的顺序，不能阻止缺蓝期间低费技能持续消费。短战斗与长战斗的最优取舍不同。这些是旧策略模型成绩，**不是本轮新增均衡策略的成绩**；约40秒停止补怪也不是40秒战斗必定结束。

## 2. 玩家设置：先少而明确

| 设置 | 建议默认 | 作用 |
| --- | --- | --- |
| 每技能自动/手动 | 四技能全自动 | 手动技能不参与普通自动候选，但可主动释放；普攻始终自动 |
| 英雄用蓝方式 | 均衡 | 可选均衡、爆发、续航；改变自动决策，不改属性 |
| 关键技能 | 英雄预设，岚牙为4 | 每英雄同时保护一个技能，允许改为治疗/护盾等；不同时冻结四份法力 |
| 为手动技能留蓝 | 关闭 | 仅在玩家明确打开时为手动关键技能储备，避免自动小技能一直等一个从未点击的大招 |

所有主动技能允许自愿切手动；首版常用操作只突出4。普通技能手动入口放在展开的技能控制区，不在五名英雄卡上同时铺20个释放按钮。没有额外的“关闭”状态：切手动且不点就可暂时停用。

三种用蓝方式共用合法性检查、无目标不空放、已有增益不无效刷新、避免纯过量治疗等基本规则；区别如下：

| 方式 | 自动行为 | 适用取舍 |
| --- | --- | --- |
| 均衡（默认） | 按技能条件释放；关键技能冷却剩余≤8秒时开始动态留蓝，救急/明显收尾可打破留蓝 | 日常自动战斗，兼顾当前收益与下一轮关键技能 |
| 爆发 | 不为未来技能额外留蓝；符合条件即可按当前职责优先级释放 | 立即压血、短窗口；可能更早枯蓝 |
| 续航 | 从关键技能上次释放后就开始计算动态储备；压低低价值补充技能频率 | 长战斗，可能降低前40秒伤害；不承诺一定优于均衡 |

先验证“均衡 + 每技能开关 + 手动4”即可；爆发/续航可以先作测试配置，验证确有可解释差异后再展示给玩家，不用同时加入拖拽技能顺序、任意脚本条件编辑器或复杂连招编程。

## 3. 自动决策顺序

每次英雄可行动时依次处理：有效手动指令 → 符合具体定义的救急技能 → 当前值得释放的关键技能 → 英雄预设普通循环 → 普攻。各英雄按职责配置，不强制全英雄使用4→2→1→3；普通技能编号与核心/配合/补短板职责仍可不同。

先过滤死亡、未学习、受控、吟唱中、冷却、真实法力和合法目标，再看收益条件与储备。查询条件不扣蓝、不取随机数；满足条件才启动施法，仍按既定时点扣蓝/起冷却、被打断不退资源。手动也必须通过这些硬条件，不取消正在执行的普攻/吟唱来偷取额外行动。

“救急”不是所有伤害技能都能自动突破储备：仅英雄明确定义的治疗、护盾、控制或防御增益有该资格，并须有相应受益目标。岚牙3可在自身≤35%生命且最近2秒实际受伤时临时提高优先级；4不是治疗技能，不能泛化成低血就必开。阈值为首版工作值，后续按过量/防御覆盖与存活校准。

## 4. 动态留蓝及解除条件

关键技能实际蓝耗记为C，剩余冷却为T，可保证的自然回蓝为g（计入已有回复抑制；临时回蓝增益若不能覆盖T，只采用这一期间能保证的最低速率，不预支未来击杀、命中回蓝或随机强化）。储备下限：

`B = max(0, C − g × T)`

允许普通自动技能消费的条件为：`当前法力 − 本次实际耗蓝 ≥ B`。B只是一条自动决策下限，不是额外资源、不扣实际法力，也不把B加到每个技能价格上。下一次行动按最新C/T/g重算；技能急速、耗蓝变化及回蓝装备都正常影响结果。

- 均衡模式仅在T≤8秒时启用；进入时法力可能已经低于B，此时先普攻/回蓝，允许下一次关键技能延后，不假称8秒窗口能保证准时释放。续航则提前计算B。
- 自动保护仅在关键技能已学会、当前可获得合法收益时启动。岚牙4须有敌方合法目标；未学1/2时不白送对应效果，但仍可增强被动，不能直接判作无效技能。
- 若关键技能已在持续生效，停止为其新一轮保留；结束后再依冷却与模式判断。法力保留不让1/2在岚牙大招期间重复付费。
- 无目标/目标不符合技能条件时不储备；其余技能照各自规则运行。关键技能进入手动后，默认解除储备，除非玩家打开“为手动技能留蓝”。
- 实际最大法力低于C时不能冻结法力等一个不可能支付的技能；显示原因并退回普通循环。回蓝为0且当前法力不足C时，自动储备解除；未来真的获得法力后再重新评估，不预支概率回蓝。
- “明显收尾”首版仅指已进入无后续补怪的清场阶段，且当前可见敌方总有效血盾预计不超过本英雄两次普攻伤害。此时解除未来储备，仍避免放明显浪费的长增益。预计伤害仅用当前面板/命中期望，非读取未来随机数或偷看后续敌人；不能在倒计时到40秒就自动清空法力。
- 救急技能和玩家手动指令可突破软储备；本次消费后重新计算，不另补罚、不锁死后续自动。技能施放后储备对象不会凭空同时施法。

岚牙15级C=100、g=4.94：4秒后大招就绪，B=80.24。当前70蓝不能自动再花34蓝放1，先普攻攒蓝；当前120蓝放1后剩86，可以放；当前110蓝放1后仅76，应等待。若4还有20秒冷却，均衡暂不留蓝；续航理论B=1.2，通常也不会妨碍普通循环。大招一就绪B升至100，已有目标且法力足够才实际释放。

储备从0到100逐步变化，不采用统一“蓝量低于30%就停放全部技能”：不同英雄耗蓝、蓝池和回蓝差异很大，百分比阈值不能代替实际支付能力。

## 5. 岚牙的首版自动条件

| 技能 | 建议条件 | 缺蓝或储备冲突时 |
| --- | --- | --- |
| 1 淬锋箭 | 有目标、充能耗尽或到期、4未接管；仍是核心附伤 | 按真实支付与B判断，不为续充无效覆盖剩余次数 |
| 2 疾弦 | 有目标、攻速增益结束、4未接管；在普通循环中优先于1 | 能放不等于必放，保留关键技能需要的蓝 |
| 3 三向追猎 | 至少2个目标；或单目标下4正在生效且精准能带来至少8个百分点命中提升；或符合上述救急条件 | 单目标常态不机械按CD放；救急可突破B，其余遵守储备 |
| 4 极限连射 | 已学习、可支付、有目标，且不是仅剩一个预计两次普攻即可击杀的目标 | 不足蓝时保护储备，普攻继续；不假定未来目标马上出现 |

普通循环仍用2→1→3；救急3可提前。3的上述条件是新增候选，不改它最多三目标、4秒精准/闪避或伤害系数。若当前命中已经100%，精准收益为0；不能把加15精准一律算成+15%实际命中。单目标未开4时暂缓3，可能损失一些伤害或防御，应在HB重跑核对，不能凭直觉称一定更优。

4期间1/2按钮显示“由4维持”，手动也不重复施放；学习等级与原接管规则不变。3仍可正常施放。首版不增加“开4前自动免费补1/2”等额外连招效果。

## 6. 手动操作与一次性指令

技能图标继续用于查看说明，保留已确认的400ms悬停/手机轻点及说明暂停；不把手机查看动作改成释放。选中英雄的技能控制区提供独立“释放”按钮与自动/手动开关。自动状态也可主动点释放，这次优先执行后继续自动；手动状态则始终等玩家下令。

建议快捷键1/2/3/4仅作用于当前明确选中的己方英雄，和技能新标签一致；焦点在输入框/模态框时禁用，长按不连发，无选中英雄不默认操纵全队。现有实现的按键映射需实施时检查冲突，本轮不修改。触屏采用按钮，不依赖右键/悬停。

首版允许每名英雄保留一条短指令，只解决“正在施法、这一刻点了却没反应”：

- 当下能放立即发起；只有行动被自身现有吟唱/动作占用时，允许等待最多1.5秒模拟时间。仍须在点击时有蓝、冷却完成、有合法目标且未受硬控。
- 已发普攻弹道和普攻冷却本身不额外算成技能行动占用，沿用正式行动契约；不为了队列给射手新增“箭飞完才能放技能”的限制。
- 缺蓝、冷却中、被控、死亡、不支持的技能组合直接反馈原因，不排一条未来可能突然触发的订单。新的有效指令替换旧指令；同键重复不叠次数，无效点击不清掉已有有效指令。
- 待执行时暂停此英雄新的自动技能消费，不阻断已开始的行动/已发弹道，也不强制关闭其它英雄自动。执行前重新验证全部条件；条件失效则取消并反馈，超时不自动延期。
- 指令绑定英雄实例，不因切换查看对象换人；可显式取消。暂停冻结到期计时。战斗结束/退出、英雄死亡、切换自动开关或用蓝预设时清理，跨关不携带一次性指令；持久设置与临时指令分开保存。
- 手动释放沿用当前英雄选敌策略/当前目标及技能本身选敌，不新增技能专属点选目标。指令等待阶段不锁旧敌人ID，实际开始施法时按现有规则确定目标；已经开始的吟唱/已经发射的攻击保持原契约，不因点击改打新单位。

暂停沿用现有规则：释放按钮可关闭说明并仅解除“说明暂停”，若还有手动/后台/旋转暂停则不施法、不新建队列，提示先继续。本版不增加暂停期间编排20个指令、恢复后同时放出的新系统。此边界保留R007既定行为。

## 7. 玩家能看懂为什么没放

仅在选中英雄详情/技能旁显示简短状态：自动、手动、缺蓝、冷却中、等待当前施法、为4留蓝、目标不合适、由4维持。展开说明可看“当前70／需要100；另留约80”，不把公式和统计词放到常用操作区。

一次点击失败给轻量反馈，自动每帧失败不刷提示；不能把“留蓝”伪装成冷却或按钮失灵。切换预设立刻影响下一次决策，不取消已开始的行动，不返还资源。设置按英雄保存，进场/招募默认均衡与全自动；跨关继承，临时救急状态/队列不继承。

## 8. 验证与实施顺序

本轮仅设计，未修改R033模型或重新运行收益试验。下一轮先在独立模型明确标记新增策略版本，再比较：原顺序、R033全程留蓝、均衡8秒、爆发、续航；同等级/装备/种子/时序测1/3/5目标、5/10/40/180秒、有限反击、缺蓝/零回蓝/回蓝装/急速装。

除DPS、清场和生存外，记录关键技能可支付后未放时间、因缺蓝延后秒数、储备导致的小技能停放时间、每技能次数、溢出回蓝、结束剩余法力和救急实际收益；满蓝不放与无法回蓝不空等应有可解释原因。对技能效果更新的资格逐项核验，不能靠查询或手动操作多触发一次攻击特效。

手动对照用预登记时点或可见状态触发脚本，不能事后按随机结果挑最佳操作。默认自动作为平衡主表；手动成绩单列，同时记录每分钟有效指令数/失败点击。不能用玩家高频操作掩盖自动策略缺陷；也不规定手动必须比自动高固定百分比。

验证场景至少包含：无目标、目标临时失效、只有残血、持续补怪与清场、0回蓝、技能实际耗蓝超过最大蓝、瞬间回蓝/耗蓝变化、技能3救急破储备、4接管1/2、队列过期/切换/控制、查看说明与其它暂停叠加。先落实自动核心和手动4，再开放普通技能开关/短队列；不改英雄伤害/蓝耗来掩盖决策问题。
